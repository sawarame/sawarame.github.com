## 使用方式

1. 將檔案拖放至此區域，或點擊選擇檔案。也可以直接貼上（Ctrl+V / Cmd+V）複製的文字或檔案。
2. 系統會自動偵測字元編碼並顯示內容預覽。如果預覽出現亂碼，請嘗試手動變更「目前的字元編碼」。
3. 在**「文字資訊」**區塊中，可以確認字元數、字數、行數以及目前的檔案大小。
4. 選擇目標字元編碼或換行符號後，系統會模擬顯示**轉換後的預估檔案大小**。
5. 點擊「轉換並下載」按鈕，即可使用新的字元編碼儲存檔案。

### 支援格式
- **字元編碼：** UTF-8、Shift_JIS、EUC-JP、ISO-2022-JP (JIS)、UTF-16、ASCII 等
- **換行符號：** LF (Unix/macOS)、CRLF (Windows)、CR (Classic Mac)

:::info[關於安全性]
🔒 所有處理皆在瀏覽器內完成，檔案內容與換行符號絕不會傳送至伺服器。
:::
