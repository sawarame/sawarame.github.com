## 使用方式

1. 請選擇或拖放包含 QR Code 的圖片檔案。
2. 解析成功後，畫面將顯示其中嵌入的文字內容。
3. 若內容為網址（URL），可直接點擊按鈕開啟網頁。
4. 擷取出的文字可透過複製按鈕輕鬆儲存至剪貼簿。

:::info[關於安全性]
🔒 上傳的圖片不會傳送至伺服器。所有解析處理均在瀏覽器內完成，充分保障您的隱私。
:::
