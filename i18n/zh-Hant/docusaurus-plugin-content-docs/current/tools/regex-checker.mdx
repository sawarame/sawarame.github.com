## 使用方式

1. **選擇預設範本或輸入正規表示式**：
   從上方的下拉式選單選擇常用範本（電子郵件、URL、郵遞區號、日期等），或直接在「正規表示式模式」輸入欄中輸入任意正規表示式。
2. **設定旗標**：
   點擊正規表示式輸入欄下方的旗標按鈕（`g`: 全域搜尋、`i`: 忽略大小寫、`m`: 多行模式、`s`: dotAll、`u`: Unicode、`y`: Sticky）以切換啟用或停用。
3. **輸入測試文字**：
   在「測試文字」區域輸入或貼上想要驗證的文字。
4. **確認比對結果與醒目提示**：
   輸入的同時即會即時進行比對，並將符合的區段以醒目提示方式標示出來。
5. **檢視擷取群組**：
   若模式中包含圓括弧 `(...)` 或具名擷取群組 `(?<name>...)`，系統將逐筆列出各個比對結果的群組擷取值與位置（起始－結束索引）。
6. **複製與 URL 分享**：
   可透過「複製模式」或「複製比對清單」按鈕將結果儲存至剪貼簿。此外，輸入狀態會自動同步至 URL 查詢參數（`?p=...&f=...&t=...`），只需直接分享網址即可還原目前的測試狀態。

## 主要功能與特色

### 1. 豐富的預設範本
內建 10 種實務上常用的正規表示式範本，點擊一下即可套用並進行測試。
- **電子郵件地址**：符合 RFC 標準的一般電子郵件格式
- **URL (HTTP/HTTPS)**：包含通訊協定的網頁連結
- **日本郵遞區號**：`100-0001` 或 `1000001`
- **日本電話號碼**：市話、手機與免付費電話
- **日期**：`YYYY-MM-DD` 或 `YYYY/MM/DD`（含具名擷取群組）
- **時間**：`HH:MM:SS` 或 `HH:MM`
- **IPv4 位址**：0.0.0.0 至 255.255.255.255
- **半形英數字**：僅由英文字母與數字組成的字串
- **HTML 標籤**：擷取起始／結束標籤與屬性
- **十六進位色碼**：`#RGB`、`#RRGGBB`、`#RRGGBBAA`

### 2. 完整的旗標支援
支援符合 JavaScript 正規表示式規範的所有主要旗標（`g`、`i`、`m`、`s`、`u`、`y`）。

### 3. 結構化的擷取群組分析
除了編號群組（`$1`、`$2`、...）外，亦完整支援 ES2018 的具名擷取群組（`(?<name>...)`）。可透過詳細資訊卡片直覺檢視各群組的值與比對範圍。

### 4. 即時醒目提示與效能顯示
以不同顏色醒目提示文字中符合的區段，並可透過工具提示檢視各比對編號與索引範圍；同時即時量測並顯示精確至毫秒等級的執行時間。

### 5. URL 同步與自動備份
您輸入的正規表示式模式、旗標與測試文字都會即時同步至 URL 查詢參數及瀏覽器的本機儲存空間（LocalStorage），即使重新整理頁面也能保留作業狀態。

:::info[關於安全性（100% 用戶端本機處理）]
🔒 所有處理均在瀏覽器內完成，您輸入的正規表示式與測試文字絕不會傳送至外部伺服器，即使是包含機密紀錄檔或個人資訊的文字也能安心驗證。
:::
