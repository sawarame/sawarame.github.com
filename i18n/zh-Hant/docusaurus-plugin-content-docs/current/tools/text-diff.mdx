## 使用方式

1. 請拖放檔案或點擊選取檔案，亦可直接貼上複製的文字或檔案（Ctrl+V / Cmd+V）加入清單。
2. 上傳的檔案將會顯示於清單中。
3. 選擇 **「左（來源）」** 與 **「右（目標）」** 單選按鈕，指定要比較的兩個檔案。
4. 畫面下方即會顯示差異結果。
5. 可在 **「雙欄檢視（Split）」** 與 **「單欄檢視（Unified）」** 之間切換，以偏好的格式檢視。
6. 啟用 **「忽略空白」** 選項後，可排除僅為縮排或空格造成的差異。

:::info 關於安全性
🔒 所有處理均在瀏覽器內完成，檔案內容絕不會傳送至伺服器。
:::
