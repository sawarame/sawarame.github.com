## 使用方式

1. 選擇檔案，或在文字區域貼上 JSON 資料。
2. 系統會即時驗證語法；若有錯誤，將會顯示錯誤訊息。
3. 選擇縮排寬度（2 個空格、4 個空格、Tab）並點擊「格式化」按鈕，即可整理排版。
4. 在「樹狀檢視」分頁中，可以透過可摺疊的樹狀結構檢視資料層級。
5. 在「TypeScript 型別定義」分頁中，可檢視自動產生的 interface，並進行複製或下載。

:::info[關於安全性]
🔒 所有處理皆在瀏覽器內完成，資料絕不會傳送至任何伺服器。
:::
