## 使用方式

1. 指定密碼長度與要使用的字元種類（符號、大寫字母、小寫字母等）。
2. 變更設定後，會自動產生新的密碼。
3. 點擊「複製」按鈕可個別複製密碼，或點擊「儲存」按鈕將產生的清單下載為文字檔。
4. 密碼的產生設定會即時反映在網址中，只要加入書籤，下次就能以相同條件快速產生密碼。

:::info 關於安全性
🔒 所有產生處理皆完全在您的瀏覽器內執行，密碼與設定內容絕不會傳送至任何伺服器。
:::
