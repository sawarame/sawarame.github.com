## 測試瀏覽器運算效能

點擊「開始測試」按鈕後，會在瀏覽器中執行高負載運算處理，並依據處理速度計算分數。

<Benchmark />

## 關於分數

本工具會從以下三個面向在瀏覽器中綜合評估效能：

- **單核心**：僅使用 1 個 Worker 進行的運算效能，接近 JavaScript 主執行緒的處理能力指標。
- **多核心**：使用裝置所有邏輯核心進行的平行運算效能，反映處理繁重工作與多工的能力。
- **圖形繪製**：在畫面上執行大量 DOM 操作與 Canvas 繪製，測量能維持畫面更新率（FPS）的極限值，直接關係到 UI 的流暢度。

## 評估等級

依據測得的分數，分為 S 到 F 等級進行評估：

- **Rank S**：無與倫比的速度，最新的高階旗艦裝置。
- **Rank A**：極為流暢，絕大多數應用程式都能極其順暢地運作。
- **Rank B**：流暢，同時執行多項任務依然游刃有餘的效能。
- **Rank C**：標準，足以應付一般網頁瀏覽的效能。
- **Rank D-F**：基本效能，在複雜的網站上可能會出現卡頓情形。

## 瀏覽器功能支援狀態

檢測瀏覽器對最新網頁技術（WebGPU、Passkeys、AV1 解碼等）的支援程度。這些技術是享受更進階、更高速網頁體驗不可或缺的要素。

:::info 關於隱私
🔒 所有測試與判定處理皆完全在您的瀏覽器內進行。裝置的具體資訊與測試結果絕不會傳送至任何伺服器。
:::
