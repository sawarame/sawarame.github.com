## 開啟彈出視窗

在 Nickmark（v2.1.0）中，所有的搜尋、新增、刪除與前往管理畫面的操作皆整合至**指令面板型彈出視窗**。

- **快捷鍵**：**`Option + Shift + D`**（macOS） / **`Alt + Shift + D`**（Windows・Linux）
  - 您可隨時於 Chrome 的 `chrome://extensions/shortcuts` 自訂按鍵配置。
- **工具列圖示**：點擊瀏覽器右上角的擴充功能圖示，也能開啟相同的彈出視窗。

:::note[空白狀態下的操作提示（Tips）]
當搜尋輸入欄為空時，輸入欄下方會顯示一則實用的操作提示（TIP）。點擊 TIP 區域即可切換至另一則提示，同時維持搜尋欄的輸入焦點不變。
:::

## 基本用法

### 1. 新增書籤（`:add` / `;add`）

1. 開啟欲加入書籤的網頁。
2. 按下 **`Option + Shift + D`**（或 **`Alt + Shift + D`**）開啟指令面板。
3. 輸入 **`:add dev`**（別名 **`:a dev`**）並按下 `Enter`。
   - 您也可以使用在日文鍵盤等環境下更容易輸入的**分號 `;`** 作為開頭（例如 `;add dev`）。
4. 面板上方會顯示完成通知，無須切換頁面即可將目前分頁儲存為 `dev`。

:::tip
- 若目前頁面已使用其他暱稱註冊過，輸入 `:add` 時，彈出視窗內會顯示既有的暱稱通知橫幅。
- 註冊完成、錯誤等所有回饋通知皆在彈出視窗內完成，即使位於 `chrome://` 等特殊頁面，也不會強制跳轉至其他分頁。
:::

### 2. 開啟書籤（搜尋與分頁切換）

1. 按下 **`Option + Shift + D`**（或 **`Alt + Shift + D`**）開啟指令面板。
2. 輸入 **`dev`**，系統會在輸入過程中即時顯示符合的建議項目。
3. 選擇候選項目（`↑` / `↓` 或 `Ctrl + N` / `Ctrl + P`），並依需求按下對應按鍵開啟：
   - **`Enter`**（或點擊）：在目前分頁開啟
   - **`Cmd / Ctrl / Alt + Enter`**：在新的前景分頁開啟
   - **`Shift + Enter`**：不關閉彈出視窗，持續在背景分頁開啟

:::info
若在設定畫面（`:prefs`）中啟用「預設在新分頁開啟」，即使不搭配修飾鍵，直接按 `Enter` 也會在新的前景分頁開啟。若同時啟用子選項「位於『新分頁』時於該分頁開啟」，則僅在目前位於新分頁畫面時，直接沿用該分頁開啟。
:::

### 3. 刪除書籤（`:rm`）

1. 開啟指令面板，並輸入 **`:rm dev`**（或 **`;rm dev`**）。
2. 確認要刪除的目標候選項目後按下 `Enter` 即可刪除。
   - 若同一個暱稱下註冊了多個 URL，系統會將各個 URL 列為候選清單，方便您精準選擇特定 URL 刪除，避免誤刪。

## 一般搜尋模式

開啟指令面板後直接輸入關鍵字，即進入一般搜尋模式（不區分大小寫）。

### 搜尋機制與排序優先權

系統會針對輸入的字串，依照以下優先順序（比對層級 ＞ 釘選 ＞ 分數由高到低 ＞ URL 升冪排序）排列候選項目：

1. **暱稱完全相符**
2. **暱稱前綴相符**
3. **暱稱部分相符**
4. **標題與 URL 跨欄位搜尋**（亦支援以空格分隔多組關鍵字的 AND 條件篩選）

### 動態 URL（`%s` 預留位置）

在註冊的 URL 中加入 **`%s`**，即可將其設為搜尋快捷指令，將第二個詞以後的輸入內容作為參數代入：

- **輸入範例**：`gh sawarame/Nickmark` → `https://github.com/sawarame/Nickmark`
- **自動編碼**：路徑區段（`?`、`#` 之前）的 `%s` 會保留 `/` 並以各路徑區段為單位進行編碼；查詢字串與雜湊區段（`?`、`#` 之後）的 `%s` 則會整體進行 URL 編碼。
- **省略參數時的行為**：若有設定預設值（`default_value`），將展開該預設值並前往對應 URL；若未設定，則前往該網站的首頁（Origin）。

### 資料夾階層管理與批次開啟

在暱稱中加入斜線（`/`），系統會自動將其整理為階層式資料夾結構（例如：`work/mail`、`work/docs`、`infra/aws/prod`）。

- **資料夾批次開啟**：在指令面板中輸入結尾帶有 `/` 的路徑（如 **`work/`**）並執行，即可將該資料夾底下所有可開啟的 URL 於背景分頁一次全部開啟。
- **中層資料夾名稱搜尋**：除了完整路徑外，也能透過中層資料夾名稱（以 `/` 分隔的區段邊界起點）進行搜尋，例如針對 `github/repo` 輸入 **`repo/`** 或 **`repo`**，若有多筆符合結果則依字母順序排列。
- **排除重複與安全上限**：重複的相同 URL 與 `javascript:` 書籤小工具會自動略過。若開啟數量超過設定的安全上限（1～100 個分頁，預設 `20` 個），彈出視窗內會跳出確認對話框。

### 執行書籤小工具（`javascript:`）

只要註冊以 `javascript:` 開頭的書籤小工具，就能在不切換頁面的情況下，直接於目前的作用中分頁上執行（使用 Chrome 135 以上版本的 `userScripts` API / `MAIN` world）。

:::warning[使用書籤小工具前的事前設定（Chrome 135 以上版本）]
若要執行 `javascript:` 書籤小工具，須前往 Chrome 的擴充功能詳細資訊頁面（`chrome://extensions` → Nickmark 的「詳細資訊」），開啟 **「允許使用者指令碼」**。若尚未允許，彈出視窗與管理畫面中將會顯示引導提示。
:::

### 瀏覽器歷史紀錄搜尋（選擇性啟用）

僅當您在設定畫面（`:prefs`）啟用「在彈出視窗搜尋中包含瀏覽器歷史紀錄」，並授予瀏覽器歷史紀錄存取權限後，一般搜尋時的書籤候選清單下方才會出現「瀏覽器歷史紀錄」區塊，顯示符合的歷史紀錄項目（最多 10 筆）。

- 已出現在書籤候選清單中的 URL 會自動排除重複。
- 從歷史紀錄項目開啟網頁不會影響書籤的學習分數。
- 由於採用選擇性授權（`optional_permissions`），在您主動啟用此功能前不會要求任何權限。

### 指數衰減演算法與釘選功能

Nickmark 會自動學習您「最近最常使用哪些 URL」：

- **分數更新公式**：`Score_new = (Score_old * 0.95 ^ elapsedDays) + 1.0`
- 使用越頻繁、越近期存取的 URL，分數就越高，並優先顯示在候選清單上方；一段時間未使用的 URL，其優先度會隨經過天數緩慢下降。
- 在管理畫面中將重要書籤設為 **釘選（`is_pinned`）**，即可讓該項目在相同比對層級中永遠固定於最上方。

## 指令模式（`:` / `;` 前綴）

在指令面板開頭輸入冒號 **`:`** 或分號 **`;`** 即可進入指令模式。以 `;` 開頭的輸入在內部會等同於 `:` 處理，自動補完時也會以標準的 `:指令` 格式展開至輸入欄。

| 指令 | 別名 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `:add [暱稱] [URL(選填)] [標題(選填)]` | `:a` | 儲存目前分頁、指定 URL（`http://`/`https://`）或 `javascript:` 書籤小工具。輸入 `:add` 時會顯示既有資料夾／暱稱的自動補完與目標預覽。 | `:add note 會議紀錄` / `:add mdlink javascript:...` |
| `:addall [暱稱]` | `:aa` | 將目前視窗中所有已開啟的分頁（不含 `chrome://` 等特殊頁面）以指定暱稱批次儲存。 | `:aa workspace` |
| `:rm [暱稱] [URL(選填)]` | — | 刪除指定的暱稱或特定 URL 項目。 | `:rm old-site` |
| `:ls` | — | 在新分頁開啟書籤清單（管理畫面）。 | `:ls` |
| `:prefs` | — | 開啟設定畫面。 | `:prefs` |
| `:help` | — | 開啟本說明與文件頁面。 | `:help` |

:::note[暱稱輸入規則（禁用字元驗證）]
在指令註冊、管理畫面編輯與 JSON 匯入中，為避免與系統語法衝突，暱稱不可包含以下字元：**空白字元、`:`, `;`, `\`, `%`, `?`, `#`, `&`, `=`, `*`, `"`, `'`, `` ` ``, `<`, `>`, `|`，以及控制字元與零寬字元**。作為資料夾階層分隔符號的斜線 **`/`** 則可正常使用。
:::

## 管理畫面（`:ls`）

在指令面板執行 **`:ls`**，或點擊面板右上角的清單圖示，即可開啟管理畫面（`list.html`）。

- **行內編輯**：只需點擊暱稱、標題或 URL 的任一儲存格，即可直接原地編輯（按 `Enter` 或移開焦點即可儲存，按 `Esc` 取消）。針對動態 URL（`%s`），也可在同一個儲存格內一併編輯省略參數時的預設值（`default_value`）。
- **各欄位篩選**：點擊暱稱、標題、URL 欄標題旁的篩選按鈕，即可透過以空格分隔的 AND 部分比對即時篩選資料。
- **排序功能**：除了可從工具列選擇「預設順序」、「最後使用時間（由新到舊／由舊到新）」、「分數（由高到低／由低到高）」之外，也支援點擊各欄標題進行排序。
- **資料夾操作列**：在上方資料夾篩選列選定特定資料夾後，即可一鍵執行「批次開啟」、「重新命名資料夾」與「刪除資料夾」。
- **匯入 / 匯出 / JSON 編輯**：
  - **匯入**：支援匯入 Nickmark 的 JSON 檔案以及 Chrome 標準書籤 HTML 檔案。匯入前可預覽內容、指定匯入目標基礎資料夾，並選擇合併或覆寫模式。
  - **以 JSON 編輯**：透過內建 JSON 編輯器批次編輯所有書籤資料。
  - **匯出**：隨時將目前資料匯出為 JSON 檔案進行備份。

## 設定畫面（`:prefs`）

在指令面板執行 **`:prefs`**，或點擊面板右上角／管理畫面右上角的齒輪圖示，即可開啟設定畫面（`preferences.html`）。

- **Google 帳號同步**：可在裝置專屬的大容量本機儲存（`chrome.storage.local`，幾乎無容量限制）與跨裝置共用的 Chrome 同步儲存（`chrome.storage.sync`，上限 100KB，自動以 8KB 分塊儲存）之間切換。切換時會顯示資料移轉對話框，方便比較本機與雲端的筆數與更新時間後選擇。
- **使用語言**：無須重新載入即可即時切換 `English` / `日本語`。
- **批次開啟的安全上限數量**：可設定資料夾批次開啟時，不顯示確認視窗即自動展開的分頁數量上限（1～100 個，預設 `20` 個）。
- **在新分頁開啟設定**：
  - 「預設在新分頁開啟」：啟用後，即使不按修飾鍵，直接按 `Enter` 也會在新的前景分頁開啟。
  - 「位於『新分頁』時於該分頁開啟」：上述選項啟用時會顯示此子設定，僅在目前分頁為新分頁畫面時沿用目前分頁開啟。
- **瀏覽器歷史紀錄搜尋**：可選擇性啟用是否在搜尋候選清單下方顯示瀏覽器歷史紀錄。
- **常用預設集（共 18 種）**：只要勾選核取方塊，即可立即啟用常用的搜尋服務（動態 URL 15 種）與實用書籤小工具（3 種）。由於僅儲存已啟用的 ID，幾乎不佔用儲存空間。
  - **搜尋服務（15 種）**：`g` (Google)、`b` (Bing)、`y` (Yahoo! ※自動切換語言)、`nv` (Naver)、`bd` (Baidu)、`ddg` (DuckDuckGo)、`yt` (YouTube)、`gh` (GitHub)、`map` (Google 地圖)、`tr` (Google 翻譯)、`wiki` (Wikipedia ※自動切換語言)、`amz` (Amazon)、`x` (X / Twitter)、`npm` (npm)、`mdn` (MDN Web Docs)
  - **書籤小工具（3 種）**：`mdlink`（複製目前頁面的 Markdown 連結 `[標題](URL)`）、`htmllink`（以 HTML＋純文字格式複製目前頁面的 `<a href="URL">標題</a>`，支援 Teams 等工具）、`wayback`（使用 Wayback Machine 開啟）

## 📥 JSON 規格

管理畫面的 JSON 編輯器、匯出與匯入功能皆採用以下規格的 JSON 格式。

### 欄位說明

- **`bookmarks`**：根物件。
  - **`{暱稱}`**：`bookmarks` 內的每個鍵即為暱稱（可使用斜線 `/` 表示資料夾階層），其值為書籤項目的陣列。
    - **`url`**：目標 URL 或 `javascript:` 書籤小工具程式碼（必填）。
    - **`title`**：書籤標題。
    - **`score`**：依據使用頻率與經過天數計算的指數衰減分數，數值越大則建議排序越前面。
    - **`last_used_at`**：最後一次使用的時間戳記（毫秒）。
    - **`created_at`**：建立書籤的時間戳記（毫秒）。
    - **`is_pinned`**（選填 / boolean）：設為 `true` 時，會在相同比對層級中固定於最上方。
    - **`default_value`**（選填 / string）：當 URL 包含 `%s`（動態 URL）且開啟時省略參數，將自動代入 `%s` 的預設值。

### 具體範例

```json
{
  "bookmarks": {
    "gh": [
      {
        "url": "https://github.com/%s",
        "title": "GitHub Repository / User",
        "score": 24.5,
        "last_used_at": 1715731200000,
        "created_at": 1715731200000,
        "is_pinned": true,
        "default_value": "sawarame/Nickmark"
      }
    ],
    "work/mail": [
      {
        "url": "https://mail.example.com",
        "title": "Team Webmail",
        "score": 10.0,
        "last_used_at": 1715731300000,
        "created_at": 1715731100000
      }
    ]
  }
}
```
