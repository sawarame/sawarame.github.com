# 功能總覽

以下介紹 TabOrigami 內建的整理功能與自訂選項。

## 彈性的整理風格（摺法）

您可以依據目前的工作情境，選擇最適合的分類方式：

- **自動安排**：由 AI 自動判斷並建立最適合的分類。
- **專注任務**：依據進行中的工作或專案將分頁歸類在一起。
- **工作與生活**：清楚區分工作相關與個人私人的分頁。
- **斷捨離**：清除不再需要的分頁。

## 自訂提示詞功能

您可以輸入自訂提示詞，以自由文字向 AI 下達額外指示，藉此打造符合個人偏好的分頁分組方式。

1. 點擊彈出視窗中的「新增自訂提示詞」。
2. 在文字輸入欄中自由輸入想提供給 AI 的指示，並點擊「儲存」按鈕。
3. 回到主畫面，選擇任一種整理風格並執行，系統所建議的分組結果就會套用您的自訂提示詞指示。

:::tip
您也可以在自訂提示詞中同時給予多項指示。例如，您可以輸入以下內容：
```
- 如果有多個相同 URL 的頁面，請只保留一個，其餘刪除。
- 請使用表情符號（Emoji）作為分頁群組名稱。
```
:::

## 還原整理前狀態（歷史紀錄功能）

若對整理結果不滿意，或想恢復到先前的分頁狀態，可以透過以下步驟還原：

1. 點擊彈出視窗中的「還原整理前狀態」。
2. 畫面會列出最多 10 筆過去執行前的狀態紀錄，請選擇想要恢復的時間點。
3. 分頁將還原至該時間點的排列與分組狀態。

## 排除已釘選的分頁

此功能可保護您習慣常駐開啟的重要分頁（已釘選分頁）。
只要啟用此設定，已釘選的分頁便不會納入整理範圍，並維持原有的位置。

請前往選項畫面開啟「整理時排除已釘選的分頁」，已釘選的分頁就會永遠被排除在整理對象之外。
