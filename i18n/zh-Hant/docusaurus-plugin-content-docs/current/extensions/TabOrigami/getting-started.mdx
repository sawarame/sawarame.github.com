# 快速開始

以下說明開始使用 TabOrigami 的基本步驟。

## 1. 取得 Gemini API 金鑰

TabOrigami 採用「BYOK（Bring Your Own Key）」模式，使用者需自行取得並設定 Google Gemini API 的 API 金鑰。請依照以下步驟取得 API 金鑰：

1. 前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 並使用 Google 帳號登入。
2. 在「API 金鑰」頁面中點擊「建立 API 金鑰」按鈕，產生新的 API 金鑰。
3. 輸入任意的金鑰名稱並選擇專案（可選擇既有專案或建立新專案）。
4. 點擊「建立金鑰」按鈕產生 API 金鑰後，請**複製該金鑰**。

## 2. 設定 API 金鑰

依照以下步驟將取得的 API 金鑰設定至 TabOrigami：

1. 點擊 Chrome 工具列上的「TabOrigami」擴充功能圖示以開啟彈出視窗。
2. 點擊畫面右上角的設定圖示 ⚙️，並註冊您的 **API 金鑰**。
3. 如有需要，可同時調整介面語言（日本語 / English）或要使用的 Gemini 模型。

## 3. 整理分頁

設定完成後，就可以實際開始整理分頁了。

1. 在彈出視窗中選擇符合目前工作情境的「摺法（整理風格）」。
2. AI 會分析您目前開啟的分頁，並以清單（預覽）形式顯示建議的分組結果。
3. 確認建議內容時，您可以透過拖放自由移動分頁位置，或取消勾選核取方塊以排除特定分頁。
4. 您也可以自由編輯分頁群組的名稱與顏色。
5. 點擊 **「執行」** 按鈕後，Chrome 的分頁就會正式套用並整理為對應的分頁群組。
