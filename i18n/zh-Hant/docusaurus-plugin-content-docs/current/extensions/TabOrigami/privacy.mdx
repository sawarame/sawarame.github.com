# TabOrigami 隱私權政策

TabOrigami（以下簡稱「本擴充功能」）將使用者的隱私視為最高優先事項，並致力於提供安全可靠的使用環境。本隱私權政策說明本擴充功能如何處理個人資訊與相關資料。

## 1. 收集的資訊與使用目的

本擴充功能為了執行分頁整理，會使用以下資訊；**這些資訊僅會於使用者的本機裝置內處理，或直接與 Google 官方的 Gemini API 進行通訊，絕不會傳送或儲存至包含開發者在內的任何第三方外部伺服器**。

* **已開啟分頁的資訊（標題、URL、頁面文字內容）**：
  為了透過 AI 進行精準的分類與整理，本擴充功能會取得上述資訊並傳送至 Gemini API。
* **Gemini API 金鑰**：
  本擴充功能採用「Bring Your Own Key（BYOK）」模式。您輸入的 API 金鑰僅會安全儲存於裝置的本機儲存空間（瀏覽器同步儲存空間），並僅用於與 Google 官方 Gemini API 進行通訊。

## 2. 資料的外部傳輸

執行分頁整理功能時，本擴充功能會將取得的分頁資訊與您設定的 API 金鑰，直接傳送至由 Google LLC 提供的「Gemini API」。

* 傳送的資料將依據 Google 的 API 服務條款及隱私權政策進行處理。
* **絕不會將任何資料傳送至開發者（Sawarame）所管理的伺服器或其他任何第三方伺服器。**

## 3. 資料儲存

* 使用者設定（API 金鑰、所選語言、模型名稱等設定資訊）以及過去的分頁整理歷史紀錄（最多 10 筆），皆儲存於您瀏覽器的本機環境（如 `chrome.storage.local` 等）。
* 當您解除安裝本擴充功能時，上述所有資料皆會完全刪除。

## 4. 安全性

本擴充功能遵循瀏覽器擴充功能最新的安全標準「Manifest V3」開發，將所需權限降至最低，並透過安全的加密連線（HTTPS）進行所有 API 請求。

## 5. 隱私權政策之修訂

本隱私權政策可能因新增功能或法規變更而不經事前通知逕行修訂。若有重大變更，我們將透過擴充功能更新說明或官方網站等管道通知使用者。

## 6. 聯絡我們

若您對本擴充功能有任何錯誤回報、意見、功能建議或隱私權相關疑問，歡迎透過 [GitHub Issues](https://github.com/sawarame/TabOrigami/issues) 與我們聯繫。
