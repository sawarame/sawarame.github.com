## 사용 방법

1. 파일을 드래그 앤 드롭하거나 클릭해 파일을 선택하세요. 복사한 텍스트나 파일을 직접 붙여넣기(Ctrl+V / Cmd+V)하여 추가할 수도 있습니다.
2. 업로드된 파일 목록이 표시됩니다.
3. **"왼쪽 (원본)"** 과 **"오른쪽 (비교 대상)"** 라디오 버튼을 선택해 비교할 두 파일을 지정하세요.
4. 화면 하단에 차이점이 표시됩니다.
5. **"분할 보기 (Split)"** 와 **"통합 보기 (Unified)"** 를 전환하여 원하는 형식으로 확인할 수 있습니다.
6. **"공백 무시"** 옵션을 활성화하면 들여쓰기나 공백만의 차이를 제외하고 비교할 수 있습니다.

:::info[보안 안내]
🔒 모든 처리는 브라우저 내에서 수행됩니다. 파일 내용이 서버로 전송되는 일은 없습니다.
:::
