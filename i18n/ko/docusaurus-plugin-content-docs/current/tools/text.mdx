## 사용 방법

1. 왼쪽 입력 영역에 텍스트를 입력하고 "저장" 버튼을 누르거나 Enter 키(설정에 따라 다름)로 저장합니다.
2. 저장된 텍스트는 오른쪽 목록에 추가되며 브라우저의 로컬 스토리지에 보관됩니다.
3. 자주 사용하는 텍스트는 핀 고정 아이콘으로 상단에 고정할 수 있습니다.
4. 복사나 일괄 다운로드 기능을 활용해 저장한 텍스트를 편리하게 사용해 보세요.

:::info 보안 안내
🔒 모든 데이터는 사용 중인 브라우저 내에 저장되며 서버로 전송되지 않습니다.
:::
