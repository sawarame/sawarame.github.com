## 사용 방법

1. **항목 입력**: "항목 목록"에 추첨할 내용을 한 줄씩 입력합니다.
2. **설정**: "한 번 나온 항목을 목록에서 제외"를 켜면 당첨된 항목이 목록에서 자동으로 삭제되어 중복 없는 추첨이 가능합니다.
3. **가져오기 / 내보내기**: 텍스트 파일을 불러와 일괄 입력하거나 작성한 목록을 파일로 저장할 수 있습니다.
4. **추첨 시작**: 버튼을 누르면 룰렛이 돌아가고 무작위로 1개의 항목이 선택됩니다.
5. **이력 관리**: 이전 당첨 결과는 "추첨 이력"에서 확인할 수 있으며 필요에 따라 초기화할 수 있습니다.

:::info 개인정보 보호 안내
🔒 입력한 데이터와 추첨 이력은 모두 브라우저의 로컬 스토리지에 저장되며 서버로 전송되지 않습니다.
:::
