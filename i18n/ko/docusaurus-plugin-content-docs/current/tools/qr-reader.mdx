## 사용 방법

1. QR 코드가 담긴 이미지 파일을 선택하거나 드래그 앤 드롭하세요.
2. 분석에 성공하면 포함된 텍스트 내용이 표시됩니다.
3. 내용이 URL인 경우 버튼을 클릭해 해당 페이지를 바로 열 수 있습니다.
4. 추출된 텍스트는 복사 버튼으로 간편하게 클립보드에 저장할 수 있습니다.

:::info 보안 안내
🔒 업로드한 이미지는 서버로 전송되지 않습니다. 모든 분석 처리가 브라우저 내에서 완료되므로 개인정보가 안전하게 보호됩니다.
:::
