## 사용 방법

1. 편집할 PDF 파일을 선택하거나 드래그 앤 드롭, 또는 클립보드에서 붙여넣기(Ctrl+V)하여 추가합니다. 여러 개의 PDF를 한 번에 추가할 수도 있습니다.
2. 이미지로 내보내려면 오른쪽 상단 설정 패널에서 출력 형식(PNG/JPEG/WebP)과 필요에 따라 최대 가로 너비를 지정합니다.
3. 파일 목록에서 미리 볼 PDF를 선택하면 하단에 전체 페이지 미리보기가 표시됩니다.
4. 추출하거나 이미지로 변환할 페이지를 클릭해 선택합니다(기본적으로 전체 선택되어 있습니다).
5. "이미지로 다운로드"를 클릭하면 선택한 페이지가 이미지 파일로 일괄 다운로드됩니다.
6. "새 PDF로 저장"을 클릭하면 선택한 페이지만 추출해 병합한 새 PDF 파일이 생성됩니다.

:::info 보안 안내
🔒 업로드한 PDF 파일은 모두 브라우저 내에서 처리됩니다. 서버로 전송되는 일은 전혀 없으므로 기밀 정보가 포함된 문서도 안전하게 이용하실 수 있습니다.
:::
