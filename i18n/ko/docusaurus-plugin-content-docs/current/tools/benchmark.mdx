## 브라우저 연산 성능 테스트

"측정 시작" 버튼을 클릭하면 브라우저에서 부하가 높은 연산 처리를 실행하고, 그 처리 속도를 바탕으로 점수를 산출합니다.

<Benchmark />

## 점수 안내

이 도구는 브라우저에서 다음 3가지 관점을 기준으로 종합적인 성능을 측정합니다.

- **싱글 코어**: 하나의 Worker만 사용한 연산 성능입니다. JavaScript 메인 스레드의 처리 능력에 가까운 지표입니다.
- **멀티 코어**: 기기가 보유한 모든 논리 코어를 사용한 병렬 연산 성능입니다. 무거운 작업이나 멀티태스킹 대응력을 보여줍니다.
- **그래픽**: 화면에서 대량의 DOM 조작과 Canvas 렌더링을 수행하여 프레임 레이트(FPS)를 유지할 수 있는 한계치를 측정합니다. UI의 부드러움과 직결됩니다.

## 평가 등급

측정된 점수를 기준으로 S부터 F까지의 등급으로 평가합니다.

- **Rank S**: 비교할 수 없는 속도. 최신 하이엔드 기기 수준입니다.
- **Rank A**: 매우 쾌적함. 대부분의 앱이 극도로 부드럽게 동작합니다.
- **Rank B**: 쾌적함. 여러 작업을 동시에 실행해도 여유가 있는 성능입니다.
- **Rank C**: 표준적. 일반적인 웹 페이지 탐색에 충분한 성능입니다.
- **Rank D-F**: 기본 성능. 복잡한 사이트에서는 동작이 느려질 수 있습니다.

## 웹 기능 지원 현황

브라우저가 최신 웹 기술(WebGPU, Passkeys, AV1 디코딩 등)을 어느 정도 지원하는지 판별합니다. 이러한 기능들은 더욱 고도화되고 빠른 웹 경험을 누리기 위해 필수적인 요소입니다.

:::info 개인정보 보호 안내
🔒 모든 측정 및 판별 처리는 사용 중인 브라우저 내에서 이루어집니다. 기기의 구체적인 정보나 측정 결과가 서버로 전송되는 일은 없습니다.
:::
