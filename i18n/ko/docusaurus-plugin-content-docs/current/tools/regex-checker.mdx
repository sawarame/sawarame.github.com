## 사용 방법

1. **프리셋 선택 또는 정규표현식 입력**:
   상단 드롭다운에서 자주 쓰이는 템플릿(이메일 주소, URL, 우편번호, 날짜 등)을 선택하거나, "정규표현식 패턴" 입력란에 원하는 정규표현식을 직접 입력합니다.
2. **플래그 설정**:
   정규표현식 입력란 아래의 플래그 버튼(`g`: 전역 검색, `i`: 대소문자 무시, `m`: 여러 줄, `s`: dotAll, `u`: Unicode, `y`: Sticky)을 클릭하여 활성/비활성을 전환합니다.
3. **테스트 대상 텍스트 입력**:
   "테스트 대상 텍스트" 영역에 검증할 텍스트를 입력하거나 붙여넣습니다.
4. **일치 결과 및 하이라이트 확인**:
   입력과 동시에 실시간으로 일치 판정이 수행되며, 해당하는 부분이 하이라이트 표시됩니다.
5. **캡처 그룹 확인**:
   패턴에 소괄호 `(...)` 또는 이름 있는 그룹 `(?<name>...)`이 포함된 경우, 각 일치 항목의 그룹 추출 결과와 위치(시작-종료 인덱스)가 목록으로 표시됩니다.
6. **복사 및 URL 공유**:
   "패턴 복사" 또는 "일치 목록 복사" 버튼으로 클립보드에 저장할 수 있습니다. 또한 입력 상태가 URL 파라미터(`?p=...&f=...&t=...`)에 자동 동기화되므로 URL을 그대로 공유하여 상태를 복원할 수 있습니다.

## 주요 기능 및 특징

### 1. 풍부한 프리셋 템플릿
실무에서 자주 사용하는 10가지 정규표현식 패턴이 미리 준비되어 있어 한 번의 클릭으로 적용하고 테스트할 수 있습니다.
- **이메일 주소**: RFC 기준을 준수하는 일반적인 이메일 주소 형식
- **URL (HTTP/HTTPS)**: 프로토콜이 포함된 웹 링크
- **일본 우편번호**: `100-0001` 또는 `1000001`
- **일본 전화번호**: 유선전화·휴대전화·수신자 부담 번호
- **날짜**: `YYYY-MM-DD` 또는 `YYYY/MM/DD` (이름 있는 캡처 그룹 포함)
- **시간**: `HH:MM:SS` 또는 `HH:MM`
- **IPv4 주소**: 0.0.0.0 ~ 255.255.255.255
- **영숫자**: 영문자와 숫자로만 구성된 문자열
- **HTML 태그**: 시작·종료 태그 및 속성 추출
- **16진수 색상 코드**: `#RGB`, `#RRGGBB`, `#RRGGBBAA`

### 2. 완벽한 플래그 지원
JavaScript 정규표현식 사양을 준수하는 모든 주요 플래그(`g`, `i`, `m`, `s`, `u`, `y`)를 지원합니다.

### 3. 캡처 그룹 구조화 추출
번호가 매겨진 그룹(`$1`, `$2`, ...)뿐만 아니라 ES2018 이름 있는 캡처 그룹(`(?<name>...)`)도 완벽하게 지원합니다. 그룹별 값과 일치 범위를 상세 카드로 시각적으로 확인할 수 있습니다.

### 4. 실시간 하이라이트 & 성능 표시
입력 중인 텍스트의 일치 부분을 색상으로 구분해 하이라이트 표시하며, 각 일치 번호와 인덱스 범위를 툴팁으로 확인할 수 있습니다. 또한 밀리초 단위의 정규표현식 실행 시간도 실시간으로 측정·표시됩니다.

### 5. URL 동기화 및 자동 백업
입력한 정규표현식 패턴, 플래그, 테스트 텍스트는 실시간으로 URL 쿼리 파라미터와 브라우저 로컬 스토리지(LocalStorage)에 동기화되므로 페이지를 새로고침해도 작업 상태를 유지할 수 있습니다.
