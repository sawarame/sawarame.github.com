## 사용 방법

1. Exif 정보를 확인하고 싶은 사진 파일을 드래그 앤 드롭하거나 클릭하여 선택합니다.
2. 선택 후 자동으로 분석이 시작되며 촬영 일시, 카메라 모델, 촬영 설정, 위치 정보 등이 표시됩니다.
3. 각 항목 옆의 복사 버튼을 클릭하면 해당 값을 클립보드에 복사할 수 있습니다.
4. GPS 정보가 있는 경우 링크를 클릭해 Google 지도에서 촬영 장소를 확인할 수 있습니다.
5. "지우기" 버튼(휴지통 아이콘)을 누르면 표시된 정보를 초기화할 수 있습니다.
6. 분석 결과 카드 내 링크를 통해 해당 이미지를 그대로 [이미지 경량화·자르기 도구](/resize)로 전달하여 Exif 정보를 삭제하거나 크기를 변경할 수도 있습니다.

:::info[보안 안내]
🔒 사진 분석은 모두 사용자의 기기(브라우저 내)에서 실행되며 외부 서버로 데이터가 전송되는 일은 전혀 없습니다. 개인정보가 완벽하게 보호됩니다.
:::
