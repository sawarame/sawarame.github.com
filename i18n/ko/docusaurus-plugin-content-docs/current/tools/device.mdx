## 표시되는 정보

- **네트워크**: 현재 공인 IP 주소를 표시합니다.
- **화면 크기**:
  - **물리적 해상도**: `window.screen`에서 가져온 전체 화면 픽셀 수입니다.
  - **창 크기**: 브라우저 표시 영역(`window.innerWidth/Height`)의 크기입니다.
- **하드웨어**:
  - **논리 코어 수**: 기기의 CPU 코어 수를 표시합니다.
  - **메모리 용량**: 대략적인 RAM 용량을 표시합니다(브라우저의 개인정보 보호 정책에 따라 제한될 수 있습니다).
- **사용자 에이전트**: 브라우저에서 전송되는 식별 문자열을 표시합니다.

:::info 개인정보 보호 안내
🔒 IP 주소 조회를 제외한 모든 정보는 브라우저 내에서 직접 가져옵니다. 수집된 기기 정보가 서버에 저장되거나 개인이 식별되는 일은 없습니다.
:::
