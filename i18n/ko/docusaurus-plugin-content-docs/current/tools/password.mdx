## 사용 방법

1. 비밀번호 길이와 사용할 문자 종류(기호, 대문자, 소문자 등)를 지정합니다.
2. 설정을 변경하면 자동으로 새 비밀번호가 생성됩니다.
3. "복사" 버튼으로 개별 복사하거나 "저장" 버튼으로 생성된 목록을 텍스트 파일로 다운로드할 수 있습니다.
4. 비밀번호 생성 설정은 URL에 반영되므로 북마크해 두면 다음에도 같은 조건으로 비밀번호를 빠르게 생성할 수 있습니다.

:::info[보안 안내]
🔒 모든 생성 처리는 사용 중인 브라우저 내에서 이루어집니다. 비밀번호나 설정 내용이 서버로 전송되지 않습니다.
:::
