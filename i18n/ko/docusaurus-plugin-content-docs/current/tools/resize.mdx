## 사용 방법

1. 용량을 줄일 이미지 파일을 드래그 앤 드롭하거나 클릭해 선택합니다(다중 선택 지원). 클립보드에서 붙여넣기(Ctrl+V)도 지원합니다.
2. 필요한 경우 각 이미지의 "자르기" 버튼으로 이미지를 자를 수 있습니다. SNS용 프리셋 비율도 제공됩니다.
3. "최적화 설정"에서 출력 형식(WebP 권장), 최대 너비, 화질 등을 조정합니다. JPEG 형식의 경우 EXIF 정보 유지 여부를 선택할 수 있습니다.
4. "최적화 시작"을 클릭하면 브라우저 내에서 변환 처리가 실행됩니다.
5. 처리가 완료된 후 "비교" 버튼으로 압축 전후의 화질을 확인하고, 문제가 없다면 "다운로드"를 클릭해 이미지를 저장하세요. 여러 장인 경우 ZIP 파일로 묶여 일괄 다운로드됩니다.

:::info 개인정보 및 보안 안내
🔒 이미지 용량 줄이기와 자르기 처리는 모두 사용자의 기기(브라우저 내)에서 실행되며, 외부 서버로 데이터가 전송되는 일은 전혀 없습니다. 민감한 이미지도 안심하고 이용하실 수 있습니다.
:::
