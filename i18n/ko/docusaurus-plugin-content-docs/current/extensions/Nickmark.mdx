## 팝업 실행 방법

Nickmark(v2.1.0)에서는 모든 검색, 등록, 삭제 및 관리 화면 이동이 **커맨드 팔레트형 팝업**으로 통합되어 있습니다.

- **단축키**: **`Option + Shift + D`**(macOS) / **`Alt + Shift + D`**(Windows·Linux)
  - 단축키 설정은 Chrome의 `chrome://extensions/shortcuts`에서 변경할 수 있습니다.
- **툴바 아이콘**: 브라우저 오른쪽 상단의 확장 프로그램 아이콘을 클릭해도 동일한 팝업이 열립니다.

:::note[입력란이 비어 있을 때의 활용 팁(TIP)]
검색 입력란이 비어 있는 상태에서는 입력란 아래에 유용한 사용 팁(TIP)이 1건 표시됩니다. TIP 영역을 클릭하면 검색 입력란의 포커스를 유지한 채 다른 팁으로 전환됩니다.
:::

## 기본 사용법

### 1. 북마크 등록하기 (`:add` / `;add`)

1. 북마크에 등록할 웹 페이지를 엽니다.
2. **`Option + Shift + D`**(또는 **`Alt + Shift + D`**)로 커맨드 팔레트를 실행합니다.
3. **`:add dev`**(별칭 **`:a dev`**)를 입력하고 `Enter`를 누릅니다.
   - 키보드 배열에 따라 입력하기 편한 **세미콜론 `;`**(예: `;add dev`)으로 명령을 시작할 수도 있습니다.
4. 팔레트 상단에 완료 알림이 표시되며, 페이지를 전환하지 않고 현재 탭이 `dev`로 저장됩니다.

:::tip
- 현재 페이지가 이미 다른 닉네임으로 등록되어 있는 경우, `:add` 입력 시 이미 등록된 닉네임을 알려 주는 배너가 팝업 안에 표시됩니다.
- 등록 완료 및 오류 등의 피드백은 모두 팝업 안에서 완결되며, `chrome://` 같은 특수 페이지에서도 다른 탭으로 강제 이동하지 않습니다.
:::

### 2. 북마크 열기 (검색 및 탭 이동)

1. **`Option + Shift + D`**(또는 **`Alt + Shift + D`**)로 커맨드 팔레트를 실행합니다.
2. **`dev`**를 입력하면 입력하는 즉시 실시간으로 후보가 추천됩니다.
3. 후보를 선택(`↑` / `↓` 또는 `Ctrl + N` / `Ctrl + P`)하고 용도에 맞는 키로 엽니다.
   - **`Enter`**(또는 클릭): 현재 탭에서 열기
   - **`Cmd / Ctrl / Alt + Enter`**: 새 포그라운드 탭에서 열기
   - **`Shift + Enter`**: 팝업을 닫지 않고 백그라운드 탭에서 연속으로 열기

:::info
설정 화면(`:prefs`)에서 「기본으로 새 탭에서 열기」를 활성화하면 보조 키 없이 `Enter`만 눌러도 새 포그라운드 탭에서 열립니다. 또한 하위 설정인 「"새 탭"일 때는 해당 탭에서 열기」를 켜면 새 탭 페이지에 있을 때만 현재 탭을 그대로 사용합니다.
:::

### 3. 북마크 삭제하기 (`:rm`)

1. 커맨드 팔레트를 실행하고 **`:rm dev`**(또는 **`;rm dev`**)를 입력합니다.
2. 삭제 대상 후보를 확인한 뒤 `Enter`를 누르면 삭제됩니다.
   - 같은 닉네임에 여러 URL이 등록되어 있는 경우 각 URL이 후보 목록으로 표시되므로, 실수로 삭제하는 것을 방지하면서 특정 URL만 선택해 삭제할 수 있습니다.

## 일반 검색 모드

커맨드 팔레트를 열고 그대로 키워드를 입력하면 일반 검색 모드로 동작합니다(대소문자는 구분하지 않습니다).

### 검색 방식 및 우선순위

입력한 문자열에 대해 다음 우선순위(일치 등급 > 고정 여부 > 점수 내림차순 > URL 오름차순)에 따라 후보가 정렬됩니다.

1. **닉네임 완전 일치**
2. **닉네임 앞부분 일치**
3. **닉네임 부분 일치**
4. **제목·URL 통합 검색** (공백으로 구분된 2개 이상 단어의 AND 필터링 지원)

### 동적 URL (`%s` 플레이스홀더)

URL에 **`%s`**를 포함해 등록하면 두 번째 단어 이후의 입력을 인수로 삽입할 수 있는 검색 단축키가 됩니다.

- **입력 예시**: `gh sawarame/Nickmark` → `https://github.com/sawarame/Nickmark`
- **자동 인코딩**: 경로 영역(`?`·`#` 이전)의 `%s`는 `/`를 유지한 채 세그먼트 단위로 인코딩하며, 쿼리·해시 영역(`?`·`#` 이후)의 `%s`는 전체를 URL 인코딩합니다.
- **인수 생략 시 동작**: 기본값(`default_value`)이 설정되어 있으면 해당 값을 적용한 URL로 이동하고, 설정되어 있지 않으면 사이트의 최상위 페이지(오리진)로 이동합니다.

### 폴더 계층 관리 및 일괄 열기

닉네임에 슬래시(`/`)를 포함하면 자동으로 폴더 계층으로 정리됩니다(예: `work/mail`, `work/docs`, `infra/aws/prod`).

- **폴더 일괄 열기**: 팔레트에서 **`work/`**처럼 끝에 `/`를 붙여 실행하면 하위에서 열 수 있는 모든 URL을 백그라운드 탭으로 한꺼번에 엽니다.
- **중간 폴더명으로 검색**: 전체 경로뿐만 아니라 `github/repo`에 대해 **`repo/`**나 **`repo`**처럼 중간 폴더명(`/`로 구분된 세그먼트 경계 기준)으로도 검색할 수 있으며, 후보가 여러 개일 경우 알파벳순으로 표시됩니다.
- **중복 제외 및 안전 상한**: 동일한 URL 중복과 `javascript:` 북마클릿은 자동으로 건너뜁니다. 설정 가능한 안전 상한 개수(1~100개, 기본 `20`개)를 초과하는 경우 확인 대화상자가 표시됩니다.

### 북마클릿 실행 (`javascript:`)

`javascript:`로 시작하는 북마클릿을 등록해 두면 페이지를 이동하지 않고 현재 활성 탭에서 직접 실행할 수 있습니다(Chrome 135 이상의 `userScripts` API / `MAIN` world 사용).

:::warning[북마클릿 사용 시 사전 설정 (Chrome 135 이상)]
`javascript:` 북마클릿을 실행하려면 Chrome 확장 프로그램 세부정보 화면(`chrome://extensions` → Nickmark의 「세부정보」)에서 **「사용자 스크립트 허용」**을 켜야 합니다. 허용되지 않은 경우 팝업 및 관리 화면에 안내가 표시됩니다.
:::

### 브라우저 방문 기록 검색 (옵트인)

설정 화면(`:prefs`)에서 「팝업 검색에 브라우저 방문 기록 포함」을 활성화하고 방문 기록 접근 권한을 허용한 경우에만, 일반 검색 시 북마크 후보 하단에 「브라우저 방문 기록」 섹션으로 일치하는 방문 기록 후보(최대 10건)가 표시됩니다.

- 이미 북마크 후보에 포함된 URL은 자동으로 중복 제외됩니다.
- 방문 기록 후보에서 페이지를 열어도 북마크 학습 점수에는 영향을 주지 않습니다.
- 권한은 옵트인 방식(`optional_permissions`)이므로 기능을 활성화하기 전에는 권한을 요청하지 않습니다.

### 지수 감쇠 알고리즘 및 고정

Nickmark는 「어떤 URL을 최근에 자주 사용하는지」를 자동으로 학습합니다.

- **점수 갱신 공식**: `Score_new = (Score_old * 0.95 ^ elapsedDays) + 1.0`
- 자주, 그리고 최근에 접속하는 URL일수록 점수가 높아져 후보 상단에 표시됩니다. 한동안 사용하지 않은 URL은 경과 일수에 따라 우선순위가 서서히 낮아집니다.
- 관리 화면에서 중요한 북마크를 **고정(`is_pinned`)**해 두면 동일한 일치 등급 내에서 항상 최상단에 고정됩니다.

## 커맨드 모드 (`:` / `;` 접두사)

팔레트 맨 앞에 콜론 **`:`** 또는 세미콜론 **`;`**을 입력하면 커맨드 모드가 됩니다. `;`로 입력한 경우에도 내부적으로 `:`와 동일하게 처리되며, 자동 완성 시 표준 `:명령` 형식으로 입력란에 반영됩니다.

| 명령어 | 별칭 | 설명 | 예시 |
| :--- | :--- | :--- | :--- |
| `:add [닉네임] [URL(선택)] [제목(선택)]` | `:a` | 현재 탭, 지정한 URL(`http://`/`https://`) 또는 `javascript:` 북마클릿을 등록합니다. `:add` 입력 중에는 기존 폴더·닉네임 자동 완성과 등록 대상 미리보기를 표시합니다. | `:add note 회의록` / `:add mdlink javascript:...` |
| `:addall [닉네임]` | `:aa` | 현재 창에 열려 있는 모든 탭(`chrome://` 등 제외)을 지정한 닉네임으로 일괄 등록합니다. | `:aa workspace` |
| `:rm [닉네임] [URL(선택)]` | — | 지정한 닉네임 또는 특정 URL 항목을 삭제합니다. | `:rm old-site` |
| `:ls` | — | 북마크 목록(관리 화면)을 새 탭에서 엽니다. | `:ls` |
| `:prefs` | — | 설정 화면을 엽니다. | `:prefs` |
| `:help` | — | 이 도움말 및 문서 페이지를 엽니다. | `:help` |

:::note[닉네임 입력 규칙 (금지 문자 유효성 검사)]
명령어 등록, 관리 화면 편집, JSON 가져오기에서는 시스템 구문과 충돌하는 문자(**공백 문자, `:`, `;`, `\`, `%`, `?`, `#`, `&`, `=`, `*`, `"`, `'`, `` ` ``, `<`, `>`, `|`, 제어 문자 및 폭 없는 문자**)를 닉네임에 사용할 수 없습니다. 폴더 계층 구분을 위한 슬래시 **`/`**는 사용할 수 있습니다.
:::

## 관리 화면 (`:ls`)

팔레트에서 **`:ls`**를 실행하거나 팔레트 오른쪽 상단의 목록 아이콘을 클릭하면 관리 화면(`list.html`)이 열립니다.

- **인라인 편집**: 닉네임, 제목, URL의 각 셀을 클릭하기만 하면 그 자리에서 바로 입력란으로 전환되어 편집할 수 있습니다(`Enter` 또는 포커스 해제 시 저장, `Esc`로 취소). 동적 URL(`%s`)의 경우 인수 생략 시 기본값(`default_value`)도 함께 편집할 수 있습니다.
- **열별 필터**: 닉네임, 제목, URL 각 열 헤더에 있는 필터 버튼으로 공백 구분 AND 부분 일치 필터링을 실시간으로 적용할 수 있습니다.
- **정렬**: 툴바에서 「기본순」, 「마지막 사용 일시(최신순 / 오래된순)」, 「점수(높은순 / 낮은순)」를 선택할 수 있으며 열 헤더 클릭을 통한 정렬도 지원합니다.
- **폴더 작업 바**: 상단 폴더 필터에서 특정 폴더를 선택하면 해당 폴더의 「일괄 열기」, 「폴더 이름 변경」, 「폴더 삭제」를 한 번의 클릭으로 실행할 수 있습니다.
- **가져오기 / 내보내기 / JSON 편집**:
  - **가져오기**: Nickmark의 JSON 파일 및 Chrome 표준 북마크 HTML 파일을 지원합니다. 가져오기 전 미리보기 확인, 대상 기본 폴더 지정, 병합/덮어쓰기 모드 선택이 가능합니다.
  - **JSON으로 편집**: 내장 JSON 편집기에서 전체 데이터를 일괄 편집할 수 있습니다.
  - **내보내기**: 현재 데이터를 JSON 파일로 백업 다운로드합니다.

## 설정 화면 (`:prefs`)

팔레트에서 **`:prefs`**를 실행하거나 팔레트 또는 관리 화면 오른쪽 상단의 톱니바퀴 아이콘을 클릭하면 설정 화면(`preferences.html`)이 열립니다.

- **Google 계정 동기화**: 기기 전용 대용량 로컬 저장소(`chrome.storage.local`, 사실상 무제한)와 여러 기기 간 공유할 수 있는 Chrome 동기화 저장소(`chrome.storage.sync`, 최대 100KB·자동 8KB 청크 분할) 사이를 전환할 수 있습니다. 전환 시 로컬과 클라우드의 데이터 개수 및 수정 일시를 비교해 선택할 수 있는 데이터 마이그레이션 대화상자가 표시됩니다.
- **사용 언어**: `English` / `日本語`를 새로고침 없이 즉시 전환할 수 있습니다.
- **일괄 열기 안전 상한 개수**: 폴더 일괄 열기 시 확인 없이 자동으로 여는 최대 탭 수(1~100개, 기본 `20`개)를 설정할 수 있습니다.
- **새 탭에서 열기 설정**:
  - 「기본으로 새 탭에서 열기」: 활성화하면 보조 키 없이 `Enter`만 눌러도 새 포그라운드 탭에서 엽니다.
  - 「"새 탭"일 때는 해당 탭에서 열기」: 위 옵션이 켜져 있을 때 표시되는 하위 설정으로, 현재 탭이 새 탭 페이지일 때만 현재 탭을 그대로 사용합니다.
- **브라우저 방문 기록 검색**: 옵트인으로 검색 후보 하단에 브라우저 방문 기록을 표시할지 설정할 수 있습니다.
- **기본 프리셋 (총 18종)**: 체크박스를 켜기만 하면 자주 사용하는 검색 서비스(동적 URL 15종)와 실용적인 북마클릿(3종)을 즉시 활성화할 수 있습니다. 활성화된 ID만 저장하므로 저장 공간을 거의 차지하지 않습니다.
  - **검색 서비스 (15종)**: `g` (Google), `b` (Bing), `y` (Yahoo! ※언어 자동 전환), `nv` (Naver), `bd` (Baidu), `ddg` (DuckDuckGo), `yt` (YouTube), `gh` (GitHub), `map` (Google 지도), `tr` (Google 번역), `wiki` (Wikipedia ※언어 자동 전환), `amz` (Amazon), `x` (X / Twitter), `npm` (npm), `mdn` (MDN Web Docs)

## 📥 JSON 사양

관리 화면의 JSON 편집기, 내보내기, 가져오기 기능에서는 다음 사양에 따른 JSON 형식을 사용합니다.

### 필드 설명

- **`bookmarks`**: 루트 객체입니다.
  - **`{닉네임}`**: `bookmarks` 내의 각 키가 닉네임(슬래시 `/`로 폴더 표현 가능)이 됩니다. 값은 북마크 항목의 배열입니다.
    - **`url`**: 이동할 URL 또는 `javascript:` 북마클릿 코드입니다(필수).
    - **`title`**: 북마크 제목입니다.
    - **`score`**: 사용 빈도와 경과 일수에 기반한 지수 감쇠 점수입니다. 값이 클수록 추천 목록에서 우선순위가 높아집니다.
    - **`last_used_at`**: 마지막으로 사용한 일시의 타임스탬프(밀리초)입니다.
    - **`created_at`**: 북마크를 등록한 일시의 타임스탬프(밀리초)입니다.
    - **`is_pinned`**(선택 / boolean): `true`인 경우 동일한 일치 등급 내에서 최상단에 고정 표시됩니다.
    - **`default_value`**(선택 / string): URL에 `%s`가 포함된 동적 URL에서 인수를 생략하고 열었을 때 `%s` 자리에 대체되는 기본값입니다.

### 구체적인 예시

```json
{
  "bookmarks": {
    "gh": [
      {
        "url": "https://github.com/%s",
        "title": "GitHub Repository / User",
        "score": 24.5,
        "last_used_at": 1715731200000,
        "created_at": 1715731200000,
        "is_pinned": true,
        "default_value": "sawarame/Nickmark"
      }
    ],
    "work/mail": [
      {
        "url": "https://mail.example.com",
        "title": "Team Webmail",
        "score": 10.0,
        "last_used_at": 1715731300000,
        "created_at": 1715731100000
      }
    ]
  }
}
```
