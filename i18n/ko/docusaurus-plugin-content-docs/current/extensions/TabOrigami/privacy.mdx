# TabOrigami 개인정보 처리방침

TabOrigami(이하 「본 확장 프로그램」)는 사용자의 개인정보 보호를 최우선으로 생각하며 안전하게 이용할 수 있는 환경을 제공하기 위해 노력하고 있습니다. 본 개인정보 처리방침에서는 본 확장 프로그램의 개인정보 및 데이터 처리 방식에 대해 안내합니다.

## 1. 수집하는 정보 및 이용 목적

본 확장 프로그램은 탭 정리를 수행하기 위해 다음 정보를 이용하지만, **이 정보들은 모두 사용자 기기 내부 또는 Google의 공식 Gemini API와의 통신에만 사용되며 개발자를 포함한 제3자의 외부 서버로 전송되거나 저장되지 않습니다**.

* **열려 있는 탭 정보(제목, URL, 페이지 내 텍스트 정보)**:
  AI를 활용한 정교한 분류 및 정리를 수행하기 위해 해당 정보를 수집하여 Gemini API로 전송합니다.
* **Gemini API 키**:
  본 확장 프로그램은 「Bring Your Own Key(BYOK)」 방식을 채택하고 있습니다. 입력된 API 키는 기기 내부의 로컬 저장소(브라우저 동기화 저장소)에만 안전하게 저장되며, Google의 공식 Gemini API와의 통신에만 사용됩니다.

## 2. 데이터의 외부 전송에 대하여

본 확장 프로그램은 탭 정리 기능을 실행할 때 Google LLC가 제공하는 「Gemini API」로 수집한 탭 정보와 사용자가 지정한 API 키를 직접 전송합니다.

* 전송된 데이터는 Google의 API 이용약관 및 개인정보 처리방침에 따라 처리됩니다.
* **개발자(Sawarame)가 관리하는 서버나 그 밖의 제3자 서버로 데이터가 전송되는 일은 일절 없습니다.**

## 3. 데이터 저장

* 사용자 설정(API 키, 선택한 언어, 모델명 등의 설정 정보) 및 과거 탭 정리 기록(최대 10건)은 사용 중인 브라우저의 로컬 환경(`chrome.storage.local` 등)에 저장됩니다.
* 이러한 데이터는 본 확장 프로그램을 제거(언인스톨)하면 완전히 삭제됩니다.

## 4. 보안

본 확장 프로그램은 브라우저 확장 프로그램의 최신 보안 기준인 「Manifest V3」를 준수하여 개발되었습니다. 불필요한 권한 요청을 최소화하고 안전한 데이터 통신(HTTPS)을 통해 API 요청을 수행합니다.

## 5. 개인정보 처리방침의 변경

본 개인정보 처리방침은 기능 추가나 법령 변경 등에 따라 사전 예고 없이 개정될 수 있습니다. 중요한 변경 사항이 있을 경우 확장 프로그램의 업데이트 노트나 공식 페이지 등을 통해 안내합니다.

## 6. 문의하기

본 확장 프로그램에 관한 오류 제보, 의견, 기능 요청 또는 개인정보 관련 문의는 [GitHub Issues](https://github.com/sawarame/TabOrigami/issues)를 통해 접수하실 수 있습니다.
