# 시작하기

TabOrigami를 시작하기 위한 기본적인 절차를 안내합니다.

## 1. API 키 발급받기

TabOrigami는 「BYOK(Bring Your Own Key)」 방식을 채택하고 있어 사용자가 직접 Google Gemini API의 API 키를 발급받아 설정해야 합니다. 다음 절차에 따라 API 키를 발급받으세요.

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속해 Google 계정으로 로그인합니다.
2. 「API 키」 메뉴에서 「API 키 만들기」 버튼을 클릭해 새 API 키를 생성합니다.
3. 원하는 키 이름을 입력하고 프로젝트를 선택합니다. 기존 프로젝트를 선택하거나 새 프로젝트를 만들어도 됩니다.
4. 「키 만들기」 버튼을 클릭해 API 키가 생성되면 **키를 복사**해 둡니다.

## 2. API 키 설정하기

발급받은 API 키를 TabOrigami에 설정하는 방법은 다음과 같습니다.

1. Chrome 확장 프로그램 「TabOrigami」 아이콘을 클릭해 팝업을 엽니다.
2. 화면 오른쪽 상단의 설정 아이콘 ⚙️을 클릭하고 **API 키**를 등록합니다.
3. 필요에 따라 언어(일본어 / 영어)나 사용할 Gemini 모델을 변경하세요.

## 3. 탭 정리하기

설정이 완료되면 실제로 탭을 정리해 보세요.

1. 팝업 화면에서 현재 작업 상황에 맞는 「접기 방식(정리 스타일)」을 선택합니다.
2. AI가 탭을 분석하고 제안 내용을 목록(미리보기)으로 표시합니다.
3. 제안 내용을 확인하면서 드래그 앤 드롭으로 탭을 이동하거나 체크박스를 해제해 정리 대상에서 제외할 수 있습니다.
4. 탭 그룹 이름과 색상도 자유롭게 편집할 수 있습니다.
5. **「실행」** 버튼을 클릭하면 Chrome 탭이 실제 그룹으로 정리됩니다.
