# 기능 개요

TabOrigami에 탑재된 탭 정리 기능과 사용자 지정 기능을 소개합니다.

## 유연한 정리 스타일 (접기 방식)

현재 작업 상황에 맞춰 가장 적합한 카테고리 분류 방식을 선택할 수 있습니다.

- **자동 (Auto)**: AI가 최적의 카테고리를 자동으로 판단하여 정리합니다.
- **작업 집중 (Task Focus)**: 진행 중인 작업이나 프로젝트별로 탭을 묶어 줍니다.
- **업무와 개인 (Work-Life)**: 업무 관련 탭과 개인적인 탭을 명확하게 분리합니다.
- **불필요한 탭 정리 (Triage)**: 불필요한 탭을 정리하여 삭제합니다.

## 사용자 지정 프롬프트 기능

사용자 지정 프롬프트를 입력해 AI에게 자유로운 텍스트로 추가 지시를 내릴 수 있습니다. 이를 통해 원하는 방식의 탭 그룹화를 구현할 수 있습니다.

1. 팝업에서 「사용자 지정 프롬프트 추가」를 클릭합니다.
2. 텍스트 입력란에 AI에게 전달할 지시 사항을 자유롭게 입력하고 「저장」 버튼을 클릭합니다.
3. 메인 화면으로 돌아와 원하는 정리 스타일을 선택해 실행하면, 사용자 지정 프롬프트의 지시까지 반영된 그룹화가 제안됩니다.

:::tip
사용자 지정 프롬프트에는 여러 지시를 동시에 입력할 수도 있습니다. 예를 들어 다음과 같은 지시를 작성할 수 있습니다.
```
- 동일한 URL의 페이지가 있으면 하나만 남기고 나머지는 삭제해 주세요.
- 탭 그룹 이름은 이모지로 지정해 주세요.
```
:::

## 정리 전으로 되돌리기 (기록 기능)

정리 결과가 마음에 들지 않거나 이전 상태로 돌아가고 싶을 때는 다음 절차로 복원할 수 있습니다.

1. 팝업에서 「정리 전으로 되돌리기」를 클릭합니다.
2. 최근 최대 10건까지의 실행 전 상태가 목록으로 표시되므로, 되돌리고 싶은 시점의 기록을 선택합니다.
3. 해당 시점의 탭 구성으로 복원됩니다.

## 고정 탭 제외

항상 열어 두는 중요한 탭(고정된 탭)을 보호하는 기능입니다.
설정을 활성화하면 고정된 탭은 정리 대상에서 제외되어 기존 위치가 그대로 유지됩니다.

옵션 화면에서 「고정 탭을 정리 대상에서 제외」를 켜 주세요. 그러면 고정된 탭은 항상 정리 대상에서 제외됩니다.
