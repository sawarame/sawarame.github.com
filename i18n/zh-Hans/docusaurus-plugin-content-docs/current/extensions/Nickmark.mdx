## 打开弹出窗口

在 Nickmark（v2.1.0）中，所有搜索、添加、删除以及前往管理页面的操作都已整合到**命令面板式弹出窗口**中。

- **快捷键**：**`Option + Shift + D`**（macOS） / **`Alt + Shift + D`**（Windows / Linux）
  - 您可以随时在 Chrome 的 `chrome://extensions/shortcuts` 中自定义快捷键。
- **工具栏图标**：点击浏览器右上角的扩展程序图标，同样会打开该命令面板。

:::note[输入框为空时的使用提示（Tips）]
当搜索输入框为空时，输入框下方会显示一条实用的使用提示（TIP）。点击 TIP 区域即可切换为另一条提示，同时搜索框会继续保持焦点状态。
:::

## 基本用法

### 1. 添加书签（`:add` / `;add`）

1. 打开想要收藏为书签的网页。
2. 按下 **`Option + Shift + D`**（或 **`Alt + Shift + D`**）打开命令面板。
3. 输入 **`:add dev`**（或简写 **`:a dev`**）并按 `Enter`。
   - 您也可以使用**分号 `;`** 作为命令前缀（例如 `;add dev`），在日语键盘或部分键盘布局下输入更加顺手。
4. 面板顶部会显示完成通知，无需切换页面即可将当前标签页保存为 `dev`。

:::tip
- 如果当前页面已经以其他别名注册过，在输入 `:add` 时，弹出窗口内会显示提示横幅，告知已注册的别名。
- 添加完成、删除或报错等所有反馈都在弹出窗口内完成，即使在 `chrome://` 等特殊页面上也不会强制跳转到其他标签页。
:::

### 2. 打开书签（搜索与标签页跳转）

1. 按下 **`Option + Shift + D`**（或 **`Alt + Shift + D`**）打开命令面板。
2. 输入 **`dev`**，系统会在输入过程中实时给出匹配的候选项建议。
3. 选择候选项（使用 `↑` / `↓` 或 `Ctrl + N` / `Ctrl + P`），并按需使用对应按键打开：
   - **`Enter`**（或点击）：在当前标签页打开
   - **`Cmd / Ctrl / Alt + Enter`**：在新的前台标签页打开
   - **`Shift + Enter`**：不关闭弹出窗口，在后台标签页连续打开

:::info
在设置页面（`:prefs`）中开启“默认在新标签页中打开”后，不按修饰键直接按 `Enter` 也会在新的前台标签页中打开书签。若同时开启子选项“当前为‘新标签页’时在当前标签页打开”，则在新标签页上时仍会直接复用当前标签页。
:::

### 3. 删除书签（`:rm`）

1. 打开命令面板，输入 **`:rm dev`**（或 **`;rm dev`**）。
2. 确认要删除的候选项后按 `Enter` 即可删除。
   - 如果同一别名下注册了多个 URL，系统会将各个 URL 作为候选项一一列出，让您准确选择特定 URL 进行删除，避免误删。

## 常规搜索模式

打开命令面板后直接输入关键词，即进入常规搜索模式（不区分大小写）。

### 搜索机制与排序优先级

针对输入的字符串，候选项将按以下优先级排序（匹配层级 ＞ 置顶 ＞ 评分降序 ＞ URL 升序）：

1. **别名完全匹配**
2. **别名前缀匹配**
3. **别名包含匹配**
4. **标题与 URL 跨字段搜索**（支持以空格分隔的多关键词 AND 条件筛选）

### 动态 URL（`%s` 占位符）

在 URL 中包含 **`%s`** 并注册后，即可将其变为搜索快捷方式，把第 2 个词及之后的输入内容作为参数嵌入 URL 中：

- **输入示例**：`gh sawarame/Nickmark` → `https://github.com/sawarame/Nickmark`
- **智能编码**：位于路径区域（`?` 或 `#` 之前）的 `%s` 会保留 `/` 并按路径段进行编码；位于查询参数或哈希区域（`?` 或 `#` 之后）的 `%s` 会整体进行 URL 编码。
- **省略参数时的行为**：如果设置了默认值（`default_value`），将用该默认值替换 `%s` 并跳转；如果未设置，则会跳转到该网站的首页（源地址 / Origin）。

### 文件夹层级管理与批量打开

在别名中包含斜杠（`/`），即可自动按文件夹层级整理书签（例如：`work/mail`、`work/docs`、`infra/aws/prod`）。

- **批量打开文件夹**：在面板中输入以 `/` 结尾的文件夹名（如 **`work/`**）并执行，即可在后台标签页中批量打开该文件夹下所有可打开的 URL。
- **中间层级文件夹搜索**：除了完整路径外，也支持按中间文件夹名称（以 `/` 分隔的路径段起点）进行搜索——例如针对 `github/repo`，输入 **`repo/`** 或 **`repo`** 即可匹配，存在多个候选时按字母顺序排列。
- **自动去重与安全上限**：重复的 URL 以及 `javascript:` 小书签会被自动跳过。如果将要打开的标签页数量超过设定的安全上限（1–100 个，默认 `20` 个），弹出窗口内会显示确认对话框。

### 执行小书签（`javascript:`）

注册以 `javascript:` 开头的小书签（Bookmarklet）后，无需跳转页面即可直接在当前活动标签页上执行脚本（基于 Chrome 135 及以上版本的 `userScripts` API / `MAIN` world）。

:::warning[使用小书签前的前置设置（Chrome 135 及以上版本）]
要执行 `javascript:` 小书签，需要在 Chrome 的扩展程序详情页（`chrome://extensions` → Nickmark 的“详情”）中开启 **“允许用户脚本”**。如果未开启，弹出窗口和管理页面会显示相应提示。
:::

### 浏览器历史记录搜索（可选开启）

仅当您在设置页面（`:prefs`）中启用了“在弹出窗口搜索中包含浏览器历史记录”并授予浏览器历史记录访问权限后，常规搜索结果的书签候选下方才会出现“浏览器历史记录”分区，展示匹配的历史记录（最多 10 条）。

- 已出现在书签候选项中的 URL 会自动去重。
- 从历史记录候选项打开页面不会影响书签的学习评分。
- 该权限采用按需授权机制（`optional_permissions`），在您主动开启前不会请求权限。

### 指数衰减算法与置顶

Nickmark 会自动学习您最近最常使用的 URL：

- **评分更新公式**：`Score_new = (Score_old * 0.95 ^ elapsedDays) + 1.0`
- 访问越频繁、越近期的 URL 评分越高，会排在候选项前列；一段时间未使用的 URL 会随天数推移逐渐降低优先级。
- 在管理页面中将重要书签设为**置顶（`is_pinned`）**后，它会在同一匹配层级内始终固定在最上方。

## 命令模式（`:` / `;` 前缀）

在命令面板开头输入冒号 **`:`** 或分号 **`;`** 即可进入命令模式。使用 `;` 输入的内容在内部会等同于 `:` 处理，自动补全时会以标准的 `:命令` 格式展开到输入框中。

| 命令 | 简写 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `:add [别名] [URL(可选)] [标题(可选)]` | `:a` | 保存当前标签页、指定的 `http://` / `https://` URL，或 `javascript:` 小书签。输入 `:add` 时会补全已有文件夹前缀/别名并实时预览保存目标。 | `:add note 会议纪要` / `:add mdlink javascript:...` |
| `:addall [别名]` | `:aa` | 将当前窗口中打开的所有标签页（`chrome://` 等特殊页面除外）以指定别名批量保存。 | `:aa workspace` |
| `:rm [别名] [URL(可选)]` | — | 删除指定别名或特定的 URL 条目。 | `:rm old-site` |
| `:ls` | — | 在新标签页中打开书签列表（管理页面）。 | `:ls` |
| `:prefs` | — | 打开设置页面。 | `:prefs` |
| `:help` | — | 打开本帮助与文档页面。 | `:help` |

:::note[别名命名规则（禁用字符校验）]
为避免与命令语法和动态 URL 冲突，在命令添加、管理页面编辑以及 JSON 导入时，别名中不能包含以下字符：**空白字符、`:`、`;`、`\`、`%`、`?`、`#`、`&`、`=`、`*`、`"`、`'`、`` ` ``、`<`、`>`、`|`，以及控制字符和零宽字符**。正斜杠 **`/`** 可用于表示文件夹层级。
:::

## 管理页面（`:ls`）

在命令面板中执行 **`:ls`**，或点击面板右上角的列表图标，即可打开管理页面（`list.html`）。

- **行内编辑**：直接点击别名、标题或 URL 的任意单元格即可就地编辑（按 `Enter` 或失去焦点时保存，按 `Esc` 取消）。对于动态 URL（`%s`），还可以在同一单元格中编辑省略参数时的默认值（`default_value`）。
- **按列筛选**：点击别名、标题、URL 列标题上的筛选按钮，即可通过空格分隔的 AND 部分匹配进行实时过滤。
- **灵活排序**：可通过工具栏下拉菜单选择“默认顺序”、“最后使用时间（最新/最早）”或“评分（最高/最低）”，也支持直接点击列标题排序。
- **文件夹操作栏**：在顶部的文件夹筛选栏中选择特定文件夹后，即可一键执行“批量打开”、“重命名文件夹”或“删除文件夹”。
- **导入 / 导出 / JSON 编辑**：
  - **导入**：支持导入 Nickmark JSON 文件及 Chrome 标准书签 HTML 文件，提供导入前预览、指定目标基础文件夹以及合并/覆盖模式选择。
  - **使用 JSON 编辑**：可在内置的 JSON 编辑器中批量编辑全部书签数据。
  - **导出**：随时将当前数据导出为 JSON 文件进行备份。

## 设置页面（`:prefs`）

在命令面板中执行 **`:prefs`**，或点击面板右上角 / 管理页面右上角的齿轮图标，即可打开设置页面（`preferences.html`）。

- **Google 账号同步**：支持在设备本地大容量存储（`chrome.storage.local`，几乎无容量限制）与跨设备共享的 Chrome 同步存储（`chrome.storage.sync`，上限 100KB，自动按 8KB 分片）之间切换。切换时会弹出数据迁移对话框，展示本地与云端的条目数量及更新时间供您对比选择。
- **界面语言**：无需刷新页面即可在 `English` / `日本語` 之间即时切换。
- **批量打开标签页的安全上限**：设置文件夹批量打开时无需确认即可自动打开的最大标签页数量（1–100 个，默认 `20` 个）。
- **在新标签页中打开设置**：
  - **默认在新标签页中打开**：启用后，不按修饰键直接按 `Enter` 也会在新的前台标签页中打开书签。
  - **当前为“新标签页”时在当前标签页打开**：开启上一项后显示的子选项，仅在当前位于浏览器“新标签页”时复用该标签页。
- **浏览器历史记录搜索**：按需开关，设置是否在书签候选项下方显示匹配的浏览器历史记录。
- **常用预设（共 18 项）**：只需勾选复选框，即可立即启用常用的搜索服务（15 种动态 URL）和实用小书签（3 种）。由于仅保存已启用的 ID，几乎不占用存储空间。
  - **搜索服务（15 种）**：`g` (Google)、`b` (Bing)、`y` (Yahoo! ※自动适配语言)、`nv` (Naver)、`bd` (Baidu)、`ddg` (DuckDuckGo)、`yt` (YouTube)、`gh` (GitHub)、`map` (Google 地图)、`tr` (Google 翻译)、`wiki` (Wikipedia ※自动适配语言)、`amz` (Amazon)、`x` (X / Twitter)、`npm` (npm)、`mdn` (MDN Web Docs)
  - **小书签（3 种）**：`mdlink`（复制当前页面的 Markdown 链接 `[标题](URL)`）、`htmllink`（以 HTML + 纯文本格式复制当前页面的 `<a href="URL">标题</a>`，适配 Teams 等应用）、`wayback`（在 Wayback Machine 中打开）

## 📥 JSON 数据规范

管理页面的 JSON 编辑器、导出及导入功能均遵循以下 JSON 格式规范：

### 字段说明

- **`bookmarks`**：根对象。
  - **`{别名}`**：`bookmarks` 内的每个键即为别名（可用 `/` 表示文件夹层级），对应的值为书签条目对象数组。
    - **`url`**：目标跳转 URL 或 `javascript:` 小书签代码（必填）。
    - **`title`**：书签标题。
    - **`score`**：基于使用频率和经过天数的指数衰减评分。数值越大，搜索建议中的排序越靠前。
    - **`last_used_at`**：最后一次使用的时间戳（毫秒）。
    - **`created_at`**：创建书签时的时间戳（毫秒）。
    - **`is_pinned`**（可选 / boolean）：设为 `true` 时，在同一匹配层级内始终置顶显示。
    - **`default_value`**（可选 / string）：当 URL 包含 `%s` 且省略参数打开时，用于替换 `%s` 的默认值。

### 示例

```json
{
  "bookmarks": {
    "gh": [
      {
        "url": "https://github.com/%s",
        "title": "GitHub Repository / User",
        "score": 24.5,
        "last_used_at": 1715731200000,
        "created_at": 1715731200000,
        "is_pinned": true,
        "default_value": "sawarame/Nickmark"
      }
    ],
    "work/mail": [
      {
        "url": "https://mail.example.com",
        "title": "Team Webmail",
        "score": 10.0,
        "last_used_at": 1715731300000,
        "created_at": 1715731100000
      }
    ]
  }
}
```
