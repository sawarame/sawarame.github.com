# TabOrigami 隐私政策

TabOrigami（以下简称“本扩展程序”）始终将用户的隐私放在首位，致力于为大家提供安全可靠的使用环境。本隐私政策旨在说明本扩展程序如何处理个人信息及相关数据。

## 1. 收集的信息及使用目的

本扩展程序会使用以下信息来完成标签页整理，但**所有信息仅在用户本地设备中处理，或仅用于与 Google 官方 Gemini API 通信，绝不会发送或保存至包括开发者在内的任何第三方外部服务器**。

* **已打开标签页的信息（标题、URL、页面正文内容）**：
  为实现基于 AI 的高质量分类与整理，本扩展程序会获取上述信息并发送至 Gemini API。
* **Gemini API 密钥**：
  本扩展程序采用“自带密钥（Bring Your Own Key，简称 BYOK）”模式。您输入的 API 密钥仅安全保存在设备本地存储（浏览器同步存储）中，且仅用于与 Google 官方 Gemini API 通信。

## 2. 关于向外部发送数据

执行标签页整理功能时，本扩展程序会将获取到的标签页信息与用户指定的 API 密钥直接发送至 Google LLC 提供的“Gemini API”。

* 发送的数据将按照 Google 的 API 服务条款和隐私政策进行处理。
* **任何数据都绝不会发送至开发者（Sawarame）管理的服务器或其他任何第三方服务器。**

## 3. 数据保存

* 用户的设置信息（API 密钥、所选语言、模型名称等）以及过往的标签页整理历史记录（最多 10 条）均保存在您浏览器的本地环境中（例如 `chrome.storage.local`）。
* 卸载本扩展程序后，上述所有数据都将被彻底删除。

## 4. 安全性

本扩展程序严格遵循浏览器扩展程序的最新安全标准“Manifest V3”进行开发，将所需权限降至最低，并通过加密通信（HTTPS）安全地发起 API 请求。

## 5. 隐私政策的变更

随着功能的新增或法律法规的变更，本隐私政策可能会在不事先通知的情况下进行修订。如有重要变更，我们将通过扩展程序更新日志或官方页面等方式告知用户。

## 6. 联系我们

如果您有关于本扩展程序的缺陷反馈、意见建议、功能需求或任何隐私相关疑问，欢迎通过 [GitHub Issues](https://github.com/sawarame/TabOrigami/issues) 与我们联系。
