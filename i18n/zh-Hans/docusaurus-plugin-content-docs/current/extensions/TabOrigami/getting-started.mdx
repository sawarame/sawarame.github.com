# 快速上手

本页介绍开始使用 TabOrigami 的基本步骤。

## 1. 获取 Gemini API 密钥

TabOrigami 采用“自带密钥（BYOK / Bring Your Own Key）”模式，因此需要用户自行获取并配置 Google Gemini API 的 API 密钥。请按以下步骤获取密钥：

1. 访问 [Google AI Studio](https://aistudio.google.com/app/apikey) 并使用 Google 账号登录。
2. 在“API keys（API 密钥）”页面中点击“Create API key（创建 API 密钥）”按钮，生成新的密钥。
3. 输入任意密钥名称并选择一个项目（既可以选择现有项目，也可以新建项目）。
4. 点击“Create key（创建密钥）”按钮生成 API 密钥后，请**复制并保存该密钥**。

## 2. 配置 API 密钥

将获取到的 API 密钥配置到 TabOrigami 中的步骤如下：

1. 点击 Chrome 工具栏中的“TabOrigami”扩展程序图标，打开弹出窗口。
2. 点击界面右上角的设置图标 ⚙️，注册您的 **API 密钥**。
3. 如有需要，可以在此调整界面语言（日语 / English）以及所使用的 Gemini 模型。

## 3. 整理标签页

完成配置后，就可以开始整理标签页了：

1. 在弹出窗口中，选择符合当前工作场景的“整理风格（折纸方式）”。
2. AI 会分析当前打开的标签页，并以列表形式展示分组建议（预览）。
3. 确认建议内容时，您可以自由拖拽标签页调整所属分组，也可以取消勾选复选框将其排除出本次整理。
4. 您还可以自由编辑标签页分组的名称和颜色。
5. 点击 **“执行”** 按钮，Chrome 中的标签页便会正式按方案完成分组整理。
