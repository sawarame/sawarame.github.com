# 功能概览

本页介绍 TabOrigami 提供的标签页整理功能与个性化自定义功能。

## 灵活的整理风格（折纸方式）

您可以根据当前的工作状态，选择最合适的分类方式：

- **自动整理**：由 AI 自动判断最合适的分类方式进行整理。
- **专注任务**：按照正在进行的工作或项目将标签页归为一组。
- **工作与生活**：清晰地区分工作相关标签页与个人娱乐标签页。
- **断舍离**：清理并关闭不需要的标签页。

## 自定义提示词功能

您可以通过输入自定义提示词，使用自由文本向 AI 提供额外指令，从而实现完全符合个人偏好的标签页分组方式。

1. 点击弹出窗口中的“添加自定义提示词”。
2. 在文本输入框中自由填写希望给 AI 的指令，然后点击“保存”按钮。
3. 返回主界面，选择任意整理风格并运行，AI 生成的分组建议便会结合您的自定义提示词指令。

:::tip
您也可以在自定义提示词中同时给出多条指令。例如，可以输入如下内容：
```
- 如果存在 URL 相同的页面，只保留一个，其余全部关闭。
- 请使用 Emoji 作为标签页分组名称。
```
:::

## 撤销整理（历史记录功能）

如果您对整理结果不满意，或者希望恢复到之前的状态，可以按照以下步骤进行还原：

1. 点击弹出窗口中的“撤销整理”。
2. 列表会显示最多最近 10 次执行整理前的状态，选择想要恢复的时间点。
3. 浏览器的标签页布局将立即恢复为该时间点的状态。

## 排除固定标签页

此功能用于保护您始终保持打开状态的重要标签页（固定标签页）。
启用该设置后，已固定的标签页将被排除在整理范围之外，保持原有位置不变。

请在选项页面中开启“整理时排除固定标签页”。开启后，固定标签页将始终不会被整理操作影响。
