## 使用方法

1. 拖放或点击选择需要压缩优化的图片文件（支持多选），也支持从剪贴板粘贴（Ctrl+V）。
2. 如有需要，可点击每张图片上的“裁剪”按钮进行裁剪，并内置了适用于社交媒体的预设比例。
3. 在“优化设置”中调整输出格式（推荐 WebP）、最大宽度、画质等参数。JPEG 格式可选择是否保留 Exif 信息。
4. 点击“开始优化”，即在浏览器本地执行转换处理。
5. 处理完成后，可通过“对比”按钮查看压缩前后的画质，确认无误后点击“下载”保存图片。多张图片将自动打包为 ZIP 文件下载。

:::info 隐私与安全
🔒 图片压缩与裁剪处理均完全在您的设备（浏览器本地）上执行，绝不会向外部服务器发送任何数据，即使处理高机密性图片也能安心使用。
:::
