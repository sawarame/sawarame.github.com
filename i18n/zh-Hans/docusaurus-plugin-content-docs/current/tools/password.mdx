## 使用方法

1. 指定密码长度及所使用的字符类型（符号、大写字母、小写字母等）。
2. 修改设置后，系统会自动生成新的密码。
3. 点击“复制”按钮可单独复制对应密码，或点击“保存”按钮将生成的密码列表下载为文本文件。
4. 密码生成设置会实时同步到当前 URL，将其添加为书签后，下次打开即可沿用相同条件快速生成密码。

:::info[关于安全]
🔒 所有生成过程均完全在您的浏览器本地执行，生成的密码与设置内容绝不会发送至任何服务器。
:::
