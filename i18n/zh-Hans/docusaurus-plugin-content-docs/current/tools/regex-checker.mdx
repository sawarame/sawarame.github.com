## 使用方法

1. **选择预设或输入正则表达式**：
   从顶部下拉菜单中选择常用模板（电子邮箱、URL、邮政编码、日期等），或在“正则表达式模式”输入框中直接输入任意正则表达式。
2. **设置修饰符（标志）**：
   点击正则表达式输入框下方的标志按钮（`g`：全局搜索、`i`：忽略大小写、`m`：多行模式、`s`：dotAll、`u`：Unicode、`y`：Sticky）来切换启用/禁用状态。
3. **输入测试文本**：
   在“测试文本”区域中输入或粘贴要验证的文本。
4. **查看匹配结果与高亮**：
   输入的同时会实时执行匹配检测，并高亮显示匹配到的内容。
5. **查看捕获组**：
   如果模式中包含圆括号 `(...)` 或命名捕获组 `(?<name>...)`，将以列表形式展示每个匹配的分组提取结果及其位置（起止索引）。
6. **复制与 URL 分享**：
   点击“复制模式”或“复制匹配列表”按钮即可保存到剪贴板。此外，输入状态会自动同步到 URL 参数（`?p=...&f=...&t=...`），直接分享 URL 即可还原当前状态。

## 主要功能与特点

### 1. 丰富的预设模板
内置 10 种实际开发中常用的正则表达式模式，一键即可套用测试：
- **电子邮箱**：符合 RFC 标准的常见电子邮箱格式
- **URL (HTTP/HTTPS)**：带协议的网页链接
- **日本邮政编码**：`100-0001` 或 `1000001`
- **日本电话号码**：固定电话、手机号码及免费电话
- **日期**：`YYYY-MM-DD` 或 `YYYY/MM/DD`（含命名捕获组）
- **时间**：`HH:MM:SS` 或 `HH:MM`
- **IPv4 地址**：0.0.0.0 至 255.255.255.255
- **半角英数字**：仅由英文字母和数字组成的字符串
- **HTML 标签**：提取开始/结束标签及属性
- **十六进制颜色代码**：`#RGB`、`#RRGGBB`、`#RRGGBBAA`

### 2. 完善的标志支持
全面支持符合 JavaScript 正则表达式规范的所有主要标志（`g`、`i`、`m`、`s`、`u`、`y`）。

### 3. 捕获组结构化提取
除了编号捕获组（`$1`、`$2`、...）外，还完整支持 ES2018 的命名捕获组（`(?<name>...)`），可在详情卡片中直观查看各组的值与匹配范围。

### 4. 实时高亮与性能统计
以不同颜色高亮显示输入文本中的匹配位置，悬停提示可查看各匹配序号和索引范围。同时实时统计并显示毫秒级的正则表达式执行耗时。

### 5. URL 同步与自动备份
输入的正则表达式模式、标志及测试文本会实时同步至 URL 查询参数和浏览器本地存储（LocalStorage），刷新页面也不会丢失工作状态。

:::info 关于安全性（100% 客户端本地处理）
🔒 所有处理均在浏览器内完成，输入的正则表达式和测试文本绝不会发送至外部服务器，包含机密日志或个人信息的文本也能安全验证。
:::
