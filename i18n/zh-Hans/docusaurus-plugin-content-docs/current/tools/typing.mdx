## 使用方法

1. **选择课程**：
   选择“1分钟课程（60秒）”或“3分钟课程（180秒）”。所选课程会自动同步到 URL 查询参数（`?course=60` / `?course=180`）。
2. **开始与倒计时**：
   点击“开始”按钮后将显示 3 秒倒计时（3 → 2 → 1），计时开始的同时会自动聚焦到输入框。
3. **确认转换后按 Enter 判定**：
   使用日语 IME 正常输入并确认转换后，在**非组合输入状态下再次按下 Enter** 即可与范例文本进行比对判定。
4. **前缀匹配消化与即时修正**：
   系统会从当前未消化文本的开头逐字比对，仅消化连续匹配的前缀部分，未匹配的剩余文字会保留在输入框中，便于直接修改或重新转换后再次提交。
5. **查看结果、最佳记录与分享**：
   倒计时归零后立即跳转至结果页面，显示总消化字数、CPM（每分钟消化字数）、完成篇数与等级评价。各课程的历史最佳成绩将自动保存至浏览器的 LocalStorage，并可通过“分享结果”按钮生成包含版本号与设备信息的成绩图片进行分享。

## 判定规则与特点

### 1. 基于转换确认的真实日语输入体验
不同于逐个罗马字按键判定的传统打字软件，本工具专注于测量包含汉字转换与英数符号混排在内的实际日语输入能力。

### 2. 半角／全角与「ー」「-」统一及提交前实时配色预览
- **提交前实时绿／红提示**：按下 Enter 提交前，输入框中的文字会实时与范例逐字比对，匹配的字符以绿色显示，不匹配的字符以红色显示。
- **半角与全角、长音符与连字符视为一致**：英文字母、数字、ASCII 符号及空格不区分半角与全角（例如 `A` 与 `Ａ`、`100%` 与 `１００％`），且长音符「`ー`」与连字符「`-`」（含全角「`－`」）也判定为相同字符。
- **严格区分大小写**：大写与小写字母严格区分（`A` 与 `a` 判定为不一致）。
- **日语字符严格比对**：平假名、片假名、汉字及日语标点进行严格匹配，并通过 Unicode `NFC` 规范化消除浊点组合字符差异。
- **全语言统一日语范例**：本工具专为日语转换打字设计，无论网站界面语言为何，均统一出题日语长句范例。

### 3. 等级评价（CPM 参考标准）
根据每分钟消化字数（CPM）评定以下 5 个等级：

- **Rank S（200 CPM 及以上）**：专家级，兼具极高转换速度与准确率。
- **Rank A（150～199 CPM）**：高级水平，实务工作中的高效率输入表现。
- **Rank B（100～149 CPM）**：实务水平，转换节奏稳定且准确。
- **Rank C（60～99 CPM）**：标准水平，满足日常日语办公输入需求。
- **Rank D（60 CPM 以下）**：入门水平，适合逐段练习准确转换。
