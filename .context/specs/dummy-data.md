# ダミーデータジェネレーター (Dummy Data Generator) 仕様書

## 1. ツール概要
* **ID**: `dummy-data`
* **名称**: ダミーデータジェネレーター
* **目的**: APIのモック、データベースのテストデータなどに利用できるダミーデータ（テストデータ）をブラウザ上で安全かつ即座に生成する。
* **主要ライブラリ**: `@faker-js/faker` （ダミーデータ生成用）

## 2. コア要件
* **完全ローカル処理**: データの生成、エクスポートなどすべての処理はクライアントサイド（ブラウザ内）で完結させること。サーバーへの通信は一切行わない。
* **状態のURL同期**: ユーザーが設定したスキーマ（フィールド構成）、選択したプリセット、生成件数などの状態をURLのクエリパラメータに同期させ、共有可能にすること。
* **多言語対応**: コンポーネント内のラベル、プレースホルダーなどはDocusaurusの `<Translate>` を用いて多言語化(i18n)すること。生成されるダミーデータ自体も、設定によってロケール（日本語/英語）を切り替えられるようにする。

## 3. 機能要件

### 3.1. プリセット機能
ユーザーがゼロからフィールドを構築する手間を省くため、以下のプリセットを用意する。
* **ユーザー情報**: ID (UUID), 氏名, メールアドレス, 電話番号, 職業, 住所
* **会社情報**: ID (UUID), 会社名, 業種, URL, 設立日
* **商品情報**: ID (UUID), 商品名, 価格, カテゴリ, 説明, バーコード(EAN)

### 3.2. スキーマ（フィールド）カスタマイズ機能
* プリセットをベースに、フィールドの「追加」「削除」「並び替え」ができること。
* 追加できるフィールドの型の例:
  * ID (UUID, 自動連番)
  * 個人情報 (氏名, 名, 姓, メール, 電話)
  * 場所 (国, 都道府県, 市区町村, 番地, 郵便番号)
  * 日付 (過去, 未来, 誕生日)
  * その他 (会社名, URL, IPアドレス, ランダム文字列, 真偽値)

### 3.3. 出力設定
* **生成件数**: 1〜1000件程度で指定可能（デフォルトは10件等）。
* **出力フォーマット**:
  * `JSON`: オブジェクトの配列として出力
  * `CSV`: ヘッダー行付きのカンマ区切りテキストとして出力
  * `SQL`: テーブル名（任意指定）に対する `INSERT INTO ...` 形式で出力

### 3.4. プレビューとエクスポート
* **リアルタイムプレビュー**: 設定を変更するたびに（または「生成」ボタン押下で）、生成された結果を画面上のテキストエリア（またはコードブロック）に表示する。
* **クリップボードへコピー**: 生成結果をワンクリックでコピーできるボタン。
* **ファイルダウンロード**: 選択したフォーマット（`.json`, `.csv`, `.sql`）でファイルをダウンロードできる機能。ファイル名は `dummy-data-YYYYMMDDHHMMSS.[ext]` とする。

## 4. UI/UX デザイン方針 (MUIv6)
* 画面を左右（または上下）に分割する。
  * **左側 (設定エリア)**: プリセット選択、フィールド一覧（ドラッグ＆ドロップや追加・削除ボタン）、生成件数、フォーマット選択、テーブル名入力（SQL時のみ）。
  * **右側 (結果エリア)**: コピー/ダウンロードボタンを備えた生成結果のプレビュー表示。
* **ダークモード対応**: MUIのテーマとDocusaurusのテーマを同期させ、視認性の高い美しいUI（例: Glassmorphismなどのモダンな質感）を提供する。

## 5. URLパラメータ設計案
状態共有のため、以下のようなクエリパラメータを設計する（長くなる場合は適切にエンコードや圧縮を検討、または主要設定のみ同期する）。
* `preset`: 選択中のプリセット名 (例: `user`, `company`)
* `count`: 生成件数
* `format`: 出力形式 (`json`, `csv`, `sql`)
* `schema`: カスタムフィールド構造（JSON文字列をBase64エンコードしたもの等）

## 6. 今後の拡張構想 (V2以降)

* リレーションを持つ複数テーブルの同時生成
