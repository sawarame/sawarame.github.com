# JSON Formatter / Validator & Type Generator

## 1. 概要
JSONデータのリアルタイム構文チェック、整形（フォーマット）、Minify（圧縮）、およびツリー表示やTypeScript型定義の自動生成を行う開発者向けツール。

## 2. 機能要件
* **入力・出力**:
  * テキストエリアへの直接入力・ペースト
  * JSONファイルの読み込み（FileReader API）
  * 整形されたJSON、または型定義ファイルのダウンロード機能
  * クリップボードへのコピー機能
* **フォーマット機能**:
  * リアルタイム構文エラーチェック（エラーがある場合はメッセージ表示）
  * インデント設定の変更（2スペース、4スペース、タブ）
  * Minify（圧縮）機能
* **ツリー表示機能**:
  * 外部ライブラリ（`react-json-view-lite` または類似のReact 18対応ライブラリ）を使用した折りたたみ可能なツリー表示
* **型定義自動生成機能**:
  * JSONデータからTypeScriptの `interface` を自動生成する機能（`json-to-ts`等を使用）
* **UIレイアウト**:
  * 3つのタブ（「JSON入力・編集」「ツリー表示」「TypeScript型定義」）を切り替えるUI

## 3. 非機能要件
* **ローカル完結**: サーバーへのデータ送信は一切行わず、全てブラウザ上で処理を完結させること（プライバシー保護と高速化のため）。
* **状態保存**: 入力されたJSONデータおよび設定（インデント幅など）は、サイズが大きくなることを想定し `localStorage` を用いて保存する。URLへの同期は行わない。
* **多言語対応**: Docusaurusの `<Translate>` と `translate()` を用いて日本語・英語に対応する。

## 4. 利用予定ライブラリ
* `react-json-view-lite` (または `react-json-tree` 等): JSONツリー表示用
* `json-to-ts`: TypeScriptの型定義生成用
* `@mui/material`: タブ、ボタン、セレクトボックスなどのUIコンポーネント

## 5. UIモックアップ
* **上部**: インデント幅の選択セレクトボックス、Minifyボタン、ファイル読み込みボタン
* **中央**: タブ切り替え（「エディタ」「ツリー表示」「TypeScript型定義」）
* **下部**: 各タブのコンテンツエリア。エディタタブには、入力テキストエリアおよび、構文エラー時のエラーメッセージ表示領域を配置する。右下や右上にコピー・ダウンロードボタンを配置。
