# 正規表現チェッカー (Regex Checker) 仕様書

## 1. ツール概要
* **ID**: `regex-checker`
* **URL**: `/tools/regex-checker`
* **ドキュメント**: `docs/tools/regex-checker.mdx` / `i18n/en/docusaurus-plugin-content-docs/current/tools/regex-checker.mdx`
* **名称**: 正規表現チェッカー (Regex Checker)
* **目的**: 正規表現とテスト対象テキストを入力し、リアルタイムにマッチ判定・構文ハイライト・キャプチャグループ抽出を行う開発者・制作者向けWebツール。
* **主要技術**: React 18, TypeScript, MUI (Material UI) v6, Docusaurus 3, Vitest 2.

## 2. コア要件
* **完全ローカル処理 (Client-Side Only)**:
  正規表現のコンパイル、マッチ判定、グループ抽出、ハイライト処理はすべてブラウザの JavaScript エンジン（V8等）内で完結。外部サーバーへの通信は一切行わず、機密ログや個人情報も安全にテスト可能。
* **状態の同期と永続化 (URL Query & LocalStorage)**:
  入力された正規表現パターン、フラグ設定、テストテキストをリアルタイムで URL クエリパラメータ（`p`, `f`, `t`）および `localStorage` に同期し、共有やリロード復元を可能にする。
* **多言語対応 (i18n)**:
  日本語（デフォルト）および英語の2言語に完全対応。すべてのUI文字列は `@docusaurus/Translate` および `translate()` 関数で国際化され、`i18n/en/code.json` に英語翻訳を定義。
* **安全性と堅牢性 (ReDoS & Crash Prevention)**:
  不正な正規表現（構文エラー）でも画面がクラッシュせず、エラーメッセージを安全に表示。ゼロ幅マッチによる無限ループ防止や、大量マッチ時の最大件数制限（1,000件）を備える。

## 3. 機能要件

### 3.1. 正規表現リアルタイム評価・コンパイル
* ユーザーが入力した正規表現パターンとフラグから動的に `new RegExp(pattern, flags)` を生成。
* 入力変更時に即座にマッチ判定を実行し、マッチ件数（`matchCount`）、マッチ有無（`hasMatch`）、実行時間（`executionTimeMs`）を算出。
* 構文エラー発生時は `try...catch` で安全に捕捉し、画面クラッシュを防いでエラーアラートを表示。

### 3.2. 正規表現フラグ (Flags) の個別設定
JavaScript 仕様に準拠した以下の 6 種類のフラグを個別にトグル可能：
* `g` (Global): すべての一致を検索
* `i` (Ignore Case): 大文字・小文字を区別しない
* `m` (Multiline): `^` と `$` が各行の先頭・末尾にマッチ
* `s` (dotAll): ドット (`.`) が改行文字 `\n` にもマッチ
* `u` (Unicode): Unicode サロゲートペアや Unicode プロパティエスケープに対応
* `y` (Sticky): `lastIndex` の位置から連続してマッチ

### 3.3. キャプチャグループ抽出 (Numbered & Named Groups)
* 各マッチに含まれる番号付きキャプチャグループ（`$1`, `$2`, ...）および ES2018 名前付きキャプチャグループ（`(?<name>...)`）を構造化抽出。
* グループ名、マッチ文字列、テキスト内での開始・終了インデックス位置を表示。
* マッチしなかった省略可能グループ（`undefined`）も安全に表示。

### 3.4. 頻出プリセットテンプレートライブラリ (10種類)
実務で頻出する以下の 10 種類のテンプレートをドロップダウンから選択可能：
1. **メールアドレス (Email Address)**: RFC互換の一般的なメール形式
2. **URL (HTTP/HTTPS)**: Webアドレス、クエリパラメータ、ハッシュ対応
3. **日本の郵便番号 (Postal Code JP)**: 3桁-4桁（ハイフン有無両対応）
4. **日本の電話番号 (Phone Number JP)**: 固定電話・携帯電話・フリーダイヤル
5. **日付 (Date YYYY-MM-DD / YYYY/MM/DD)**: 名前付きグループ（year, month, day）付き
6. **時刻 (Time HH:MM:SS / HH:MM)**: 24時間表記の時刻
7. **IPv4 アドレス (IPv4 Address)**: 0.0.0.0 〜 255.255.255.255
8. **半角英数字 (Alphanumeric)**: 英数字のみの文字列
9. **HTML タグ (HTML Tags)**: 開始/終了タグ・自己終了タグ・属性・タグ名抽出
10. **16進数カラーコード (Hex Color Code)**: `#RGB`, `#RRGGBB`, `#RRGGBBAA`

### 3.5. リアルタイム・テキストハイライト表示
* 対象テキストを「マッチ部分」と「非マッチ部分」の連続したセグメント配列（`HighlightSegment[]`）に分解。
* マッチ箇所を交代配色（奇数番目/偶数番目で視認性の高いスタイル）で `<mark>` レンダリング。
* 各ハイライト要素にホバーすると、マッチ番号と開始・終了インデックスをツールチップで表示。

### 3.6. アクション機能
* **パターンをコピー**: スラッシュとフラグ付きの正規表現形式（例: `/[a-z]+/gi`）でクリップボードにコピー。パターン入力カードヘッダー、入力枠内（エンドアドーンメント）、および結果パネルの各ボタンからワンクリックでコピー可能。
* **マッチ一覧をコピー**: 抽出された全マッチ文字列を改行区切りでクリップボードにコピー。
* **単一マッチのコピー**: 各マッチ詳細カードから該当マッチ文字列を個別にコピー。
* **全クリア**: パターンとテキストを一括リセット。
* **サンプルテキスト挿入**: 選択中プリセットのサンプルテキストをワンクリックで挿入。

## 4. URL クエリパラメータ仕様 (URL Parameter Schema)

| パラメータ名 | キー | 型 | デフォルト値 | 説明 |
|---|---|---|---|---|
| 正規表現パターン | `p` | string (URI Encoded) | `""` | 入力された正規表現文字列 (例: `\d{3}-\d{4}`) |
| フラグ | `f` | string | `"g"` | 選択されたフラグ文字の連結 (例: `"gim"`) |
| テスト対象テキスト | `t` | string (URI Encoded) | `""` | 短いテスト用テキスト (500文字以下の場合のみ同期) |

- **同期ルール**:
  - パターン・フラグ・テキストの変更時に `history.replace` により URL を更新。
  - 初期ロード時に `location.search` を安全にパースして復元。
  - URL パラメータが存在しない場合は `localStorage` (`sawara_regex_checker_state`) からの前回セッション復元を試行。

## 5. UI/UX デザイン方針 (MUI v6 & DESIGN.md 準拠)
* **テーマ同期**: ルートコンポーネントを `<MuiTheme>` でラップし、Docusaurus のカラーモード（Light / Dark）と完全同期。
* **レイアウト**:
  - 上部ツールバー: プリセットテンプレート選択、全クリアボタン。
  - 2 カラムレスポンシブグリッド:
    - **左カラム (入力パネル)**: パターン入力欄（`/` プレフィックス/サフィックス装飾）、フラグ切り替えボタングループ、テスト対象テキストエリア、文字数/行数カウンター。
    - **右カラム (結果パネル)**: ステータスバッジ（マッチ件数・実行時間）、コピーアクションボタン、リアルタイムハイライト表示ビューア、マッチ詳細 & キャプチャグループ展開リスト。
* **レスポンシブ対応**: デスクトップでは 2 カラム横並び、モバイル・タブレットでは縦並び 1 カラムに自動適応。

## 6. セキュリティ・安全性対策 (Safety & ReDoS Guards)
1. **ゼロ幅マッチ無限ループ対策**:
   `/(?=a)/g` や `/^/gm` などの長さ0のマッチ時に、`regex.lastIndex` を強制インクリメント（Unicodeサロゲートペア考慮）してブラウザのフリーズを防止。
2. **最大マッチ件数リミッター**:
   大量のマッチ（`\w` を数万文字に適用等）による DOM 描画負荷やメモリ消費を防止するため、最大 1,000 件で走査を打ち切り、警告メッセージ（`isTruncated: true`）を表示。
3. **構文エラーの完全トラップ**:
   正規表現のコンパイル例外を `try...catch` で捕捉し、UI クラッシュを回避。
