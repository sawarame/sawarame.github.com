## 従来のタイピングソフトとの違い

従来の一般的なタイピングソフトは、画面に表示されたアルファベット（ローマ字）を 1 文字ずつ打っていく形式が中心でした。キーの位置を覚える基礎練習としては有効な一方で、実際の日本語入力で欠かせない「漢字への変換」「文節の区切り方の判断」「変換候補の選択と確定」といった操作までは練習しづらいという不足がありました。

本ツールでは、普段お使いの日本語入力システム（IME）を使って実際に変換・確定した文章を課題文と照合します。単にローマ字を速く打つだけでなく、頭の中で文章を組み立てながら適切なタイミングで変換・確定するまでの一連の流れを含めて、本来の日本語タイピング力を鍛えることができます。

さらに、メール・チャット・資料作成・開発業務といった実務の現場では、日本語の文章だけでなく数字や記号（`%`、`/`、`-`、`:`、`()` など）、アルファベットが頻繁に混在します。本ツールでは、これらを自然に含んだ長文を同時に打ち切る形式にすることで、入力モードの切り替えや記号入力・変換のコツまで含めた、より実践的なタイピング練習ができるようになっています。

## 使い方

1. **タイピング練習モーダルを開いてコースを選択**:
   「タイピング練習を開始」ボタンを押すと練習用モーダルが開きます。「1分コース（60秒）」「3分コース（180秒）」「5分コース（300秒）」「10分コース（600秒）」の4種類からコースを選択します。
2. **スタートとカウントダウン**:
   あらかじめ日本語入力（IME）を ON にしたうえで「スタート」ボタンを押すと、3 秒カウントダウン（3 → 2 → 1）が始まります。開始と同時に入力欄へ自動でフォーカスが当たります。（※カウントダウン中・プレイ中は誤操作防止のため背景クリックや Esc キーではモーダルが閉じません。終了したい場合は右上の「×」ボタンまたは「中断」ボタンを使用してください。）
3. **変換確定して Enter で判定**:
   普段通り日本語 IME で入力・変換確定したあと、**変換中でない状態でもう一度 Enter** を押すと例文との照合が実行されます。
4. **先頭一致による消化と修正**:
   例文の未消化部分の先頭から一致した文字数だけが消化され、不一致だった残りの文字は入力欄にそのまま残ります。残った部分を修正・再変換してそのまま再 Enter できます。
5. **結果の確認・記録と共有**:
   制限時間が 0 秒になると、入力欄に残っている未送信の文字も自動で先頭一致判定・集計したうえで即座に結果画面へ遷移します。総消化文字数・CPM（1分あたりの消化文字数）・完走文章数・ランク評価を確認でき、コース別の自己ベストはブラウザの LocalStorage に自動保存されます。「結果を共有」ボタンからバージョンやデバイス情報入りのスコア画像を生成して SNS 等へ共有できます。

## 判定ルールと特徴

### 1. 変換確定ベースのリアルな日本語入力
IME で変換確定した文字列を課題文と照合して判定します。文節ごとに細かく確定して Enter しても、長いフレーズをまとめて変換確定してから Enter しても構いません。予測変換を含め、普段の日本語入力スタイルのまま測定できます。

### 2. 英数字・記号の半角／全角統一、「ー」と「-」の同一視、送信前プレビュー
- **送信前リアルタイム色分け**: Enter で送信する前でも、入力欄内の文字を課題文と1文字ずつ照合し、合っている文字は緑・合っていない文字は赤で表示します。
- **例文中の半角スペースを可視化**: 課題文に含まれる半角スペースには控えめな「`␣`」風の印が表示されるため、スペースの位置を見落とさずに入力できます。
- **半角・全角および長音・ハイフンを同一視**: アルファベット・数字・ASCII記号・スペースは半角でも全角でも同一視され（例: `A` と `Ａ`、`100%` と `１００％`）、長音符「`ー`」とハイフン「`-`」（全角「`－`」含む）も同じ文字として判定されます。
- **大文字・小文字は厳密区別**: `A` と `a` は別文字として判定されます。
- **日本語文字は厳密一致**: ひらがな・カタカナ・漢字・句読点（`、` `。`）・括弧などはそのまま厳密に照合します（濁点・半濁点の結合表現差は Unicode NFC 正規化で吸収）。

### 3. ランク評価（CPM 目安）
1分あたりの消化文字数（CPM）に応じて、以下の 5 段階でランクを判定します。

- **Rank S（200 CPM 以上）**: エキスパート級。変換込みで驚異的なスピードと正確さ。
- **Rank A（150〜199 CPM）**: 上級レベル。実務でも極めて高い入力パフォーマンス。
- **Rank B（100〜149 CPM）**: 実務レベル。安定した変換とテンポで入力可能。
- **Rank C（60〜99 CPM）**: 標準レベル。日常業務に十分な日本語入力速度。
- **Rank D（60 CPM 未満）**: 入門レベル。焦らず一文節ずつ正確に確定する練習に最適。

:::info[プライバシーについて（完全ローカル処理）]
🔒 入力内容の判定および自己ベストの保存（LocalStorage）はすべてブラウザ内で完結し、外部サーバーへデータが送信されることは一切ありません。
:::
