## 使い方

1. **プリセットの選択または正規表現の入力**:
   上部のドロップダウンから頻出テンプレート（メールアドレス、URL、郵便番号、日付など）を選択するか、「正規表現パターン」入力欄に任意の正規表現を直接入力します。
2. **フラグの設定**:
   正規表現入力欄の下にあるフラグボタン（`g`: グローバル検索, `i`: 大文字小文字無視, `m`: 複数行, `s`: dotAll, `u`: Unicode, `y`: Sticky）をクリックして有効/無効を切り替えます。
3. **テスト対象テキストの入力**:
   「テスト対象テキスト」エリアに検証したいテキストを入力またはペーストします。
4. **マッチ結果とハイライトの確認**:
   入力と同時にリアルタイムでマッチ判定が行われ、該当箇所がハイライト表示されます。
5. **キャプチャグループの確認**:
   パターンに丸括弧 `(...)` や名前付きグループ `(?<name>...)` が含まれている場合、各マッチのグループ抽出結果や位置（開始-終了インデックス）が一覧表示されます。
6. **コピーとURL共有**:
   「パターンをコピー」または「マッチ一覧をコピー」ボタンでクリップボードへ保存できます。また、入力状態はURLパラメータ（`?p=...&f=...&t=...`）に自動同期されるため、URLをそのまま共有して状態を復元できます。

## 主な機能と特徴

### 1. 豊富なプリセットテンプレート
実務でよく使われる10種類の正規表現パターンがあらかじめ用意されており、ワンクリックで適用してテストできます。
- **メールアドレス**: RFC準拠の一般的なメールアドレス形式
- **URL (HTTP/HTTPS)**: プロトコル付きWebリンク
- **日本の郵便番号**: `100-0001` または `1000001`
- **日本の電話番号**: 固定電話・携帯電話・フリーダイヤル
- **日付**: `YYYY-MM-DD` または `YYYY/MM/DD`（名前付きキャプチャグループ付き）
- **時刻**: `HH:MM:SS` または `HH:MM`
- **IPv4 アドレス**: 0.0.0.0 〜 255.255.255.255
- **半角英数字**: 英字と数字のみで構成された文字列
- **HTML タグ**: 開始・終了タグおよび属性の抽出
- **16進数カラーコード**: `#RGB`, `#RRGGBB`, `#RRGGBBAA`

### 2. 充実したフラグサポート
JavaScript の正規表現仕様に準拠したすべての主要フラグ（`g`, `i`, `m`, `s`, `u`, `y`）に対応しています。

### 3. キャプチャグループの構造化抽出
番号付きグループ（`$1`, `$2`, ...）に加えて、ES2018 の名前付きキャプチャグループ（`(?<name>...)`）にも完全対応。グループごとの値や一致範囲を詳細カードで視覚的に確認できます。

### 4. リアルタイム・ハイライト & パフォーマンス表示
入力中のテキストの該当箇所を色分けでハイライト表示し、各マッチ番号やインデックス範囲をツールチップで確認できます。また、ミリ秒単位の正規表現実行時間もリアルタイムに計測・表示されます。

### 5. URL同期と自動バックアップ
入力した正規表現パターンやフラグ、テストテキストはリアルタイムに URL クエリパラメータおよびブラウザのローカルストレージ（LocalStorage）に同期されるため、ページをリロードしても作業状態を維持できます。

:::info セキュリティについて (100%クライアントサイド完結)
🔒 処理はすべてブラウザ内で行われ、入力された正規表現やテストテキストが外部サーバーに送信されることは一切ありません。機密ログや個人情報を含むテキストも安全に検証可能です。
:::
