## 使い方

1. **プリセットの選択**: 「ユーザー情報」「会社情報」など用途に合ったプリセットを選択します。
2. **フィールドのカスタマイズ**: 必要に応じて、特定の項目の追加、削除、データ型の変更を行えます。
3. **出力形式の設定**: 生成したい件数と出力形式（JSON、CSV、SQL）を指定します。
4. **データの生成**: 「データ生成」ボタンを押すと、プレビュー画面に結果が表示されます。
5. **保存**: クリップボードにコピー、またはファイルとしてダウンロードして利用します。

:::info セキュリティとプライバシーについて
🔒 すべてのダミーデータ生成処理はブラウザ内（クライアントサイド）で実行されます。入力した設定や生成結果がサーバーに送信されることは一切ありません。
:::
