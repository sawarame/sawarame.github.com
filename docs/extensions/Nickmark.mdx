## ポップアップの起動方法

Nickmark（v2.1.0）では、すべての検索・登録・削除・管理画面への移動が**コマンドパレット型ポップアップ**に統合されています。

- **ショートカットキー**: **`Option + Shift + D`**（macOS） / **`Alt + Shift + D`**（Windows・Linux）
  - キー割り当ては Chrome の `chrome://extensions/shortcuts` から変更できます。
- **ツールバーアイコン**: ブラウザ右上の拡張機能アイコンをクリックしても同じポップアップが開きます。

:::note[空欄時の活用ヒント（Tips）]
検索入力欄が空の状態では、入力欄の下に便利な使い方ヒント（TIP）が 1 件表示されます。TIP 領域をクリックすると別のヒントへ切り替わり、検索欄へのフォーカスはそのまま維持されます。
:::

## 基本的な使い方

### 1. ブックマークを登録する（`:add` / `;add`）

1. ブックマークに登録したい Web ページを開きます。
2. **`Option + Shift + D`**（または **`Alt + Shift + D`**）でコマンドパレットを起動します。
3. **`:add dev`**（エイリアス **`:a dev`**）と入力して `Enter` を押します。
   - 日本語キーボードなどで入力しやすい**セミコロン `;`**（例: `;add dev`）から始めることもできます。
4. パレット上部に完了通知が表示され、ページを切り替えることなく現在のタブが `dev` として保存されます。

:::tip
- 現在のページがすでに別のニックネームで登録されている場合は、`:add` 入力時に既登録ニックネームのお知らせバナーがポップアップ内に表示されます。
- 登録完了・エラーなどのフィードバックはすべてポップアップ内で完結し、`chrome://` などの特殊ページ上でも別タブへ強制遷移しません。
:::

### 2. ブックマークを開く（検索とタブ遷移）

1. **`Option + Shift + D`**（または **`Alt + Shift + D`**）でコマンドパレットを起動します。
2. **`dev`** と入力すると、入力中からリアルタイムに候補がサジェストされます。
3. 候補を選択し（`↑` / `↓` または `Ctrl + N` / `Ctrl + P`）、用途に応じたキーで開きます。
   - **`Enter`**（またはクリック）: 現在のタブで開く
   - **`Cmd / Ctrl / Alt + Enter`**: 新しいフォアグラウンドタブで開く
   - **`Shift + Enter`**: ポップアップを閉じずに、バックグラウンドタブで連続して開く

:::info
設定画面（`:prefs`）で「デフォルトで別タブで開く」を有効にすると、修飾キーなしの `Enter` でも新しいフォアグラウンドタブで開くようになります。さらにサブ設定「“新しいタブ”のときはそのタブで開く」を有効にすれば、新しいタブページ上にいるときだけ現在のタブをそのまま利用できます。
:::

### 3. ブックマークを削除する（`:rm`）

1. コマンドパレットを起動し、**`:rm dev`**（または **`;rm dev`**）と入力します。
2. 削除対象の候補を確認して `Enter` を押すと削除されます。
   - 同じニックネームに複数の URL が登録されている場合は、各 URL が候補として一覧表示されるため、誤削除を防ぎつつ特定の URL だけを選んで削除できます。

## 通常検索モード

コマンドパレットを開いてそのままキーワードを入力すると、通常検索モードとして動作します（大文字・小文字は区別しません）。

### 検索の仕組みと優先順位

入力された文字列に対して、以下の優先順位（マッチ度ティア ＞ ピン留め ＞ スコア降順 ＞ URL昇順）で候補が並びます。

1. **ニックネーム完全一致**
2. **ニックネーム前方一致**
3. **ニックネーム部分一致**
4. **タイトル・URL 横断検索**（2 語以上のスペース区切り AND 絞り込みにも対応）

### 動的 URL（`%s` プレースホルダー）

URL に **`%s`** を含めて登録すると、2 語目以降の入力を引数として埋め込める検索ショートカットになります。

- **入力例**: `gh sawarame/Nickmark` → `https://github.com/sawarame/Nickmark`
- **自動エンコード**: パス領域（`?`・`#` より前）の `%s` は `/` を保持したままセグメント単位でエンコードし、クエリ・ハッシュ領域（`?`・`#` 以降）の `%s` は全体を URL エンコードします。
- **引数省略時の動作**: デフォルト値（`default_value`）が設定されていればその値を展開した URL へ遷移し、未設定の場合はサイトのトップページ（オリジン）へ遷移します。

### フォルダ階層管理と一括オープン

ニックネームにスラッシュ（`/`）を含めると、自動的にフォルダ階層として整理されます（例: `work/mail`、`work/docs`、`infra/aws/prod`）。

- **フォルダ一括オープン**: パレットで **`work/`** のように末尾に `/` を付けて実行すると、配下の開ける URL をバックグラウンドタブで一括オープンします。
- **途中フォルダ名での検索**: フルパスだけでなく、`github/repo` に対する **`repo/`** や **`repo`** のように途中のフォルダ名（`/` 区切りのセグメント境界起点）でも検索でき、複数候補がある場合はアルファベット順で表示されます。
- **重複除外と安全上限**: 同一 URL の重複や `javascript:` ブックマークレットは自動的にスキップされます。設定可能な安全上限件数（1〜100件、デフォルト `20` 件）を超える場合は確認ダイアログが表示されます。

### ブックマークレット実行（`javascript:`）

`javascript:` で始まるブックマークレットを登録しておくと、ページ遷移せずに現在のアクティブタブ上で直接実行できます（Chrome 135 以降の `userScripts` API / `MAIN` world を使用）。

:::warning[ブックマークレット利用時の事前設定（Chrome 135 以降）]
`javascript:` ブックマークレットを実行するには、Chrome の拡張機能詳細画面（`chrome://extensions` → Nickmark の「詳細」）で **「ユーザー スクリプトを許可する」** をオンにする必要があります。未許可の場合はポップアップや管理画面に案内が表示されます。
:::

### ブラウザ履歴検索（オプトイン）

設定画面（`:prefs`）で「ポップアップ検索にブラウザ履歴を含める」を有効化し、ブラウザ履歴へのアクセス権限を許可した場合にのみ、通常検索時のブックマーク候補の下部に「ブラウザ履歴」セクションとして一致する履歴候補（最大 10 件）が表示されます。

- すでにブックマーク候補に含まれる URL は自動で重複除外されます。
- 履歴候補からページを開いてもブックマークの学習スコアには影響しません。
- 権限はオプトイン形式（`optional_permissions`）のため、有効化するまで許可を求められることはありません。

### 指数減衰アルゴリズムとピン留め

Nickmark は「どの URL を最近よく使っているか」を学習します。

- **スコア更新式**: `Score_new = (Score_old * 0.95 ^ elapsedDays) + 1.0`
- 頻繁・最近アクセスする URL ほどスコアが高くなり候補の上位に表示されます。しばらく使っていない URL は経過日数に応じて緩やかに優先度が下がります。
- 管理画面から重要なブックマークを **ピン留め（`is_pinned`）** しておくと、同じマッチ度ティア内で常に上位に固定されます。

## コマンドモード（`:` / `;` プレフィックス）

パレットの先頭にコロン **`:`** またはセミコロン **`;`** を入力するとコマンドモードになります。`;` で入力した場合も内部で `:` と同等に扱われ、補完時は標準の `:コマンド` 形式で入力欄に展開されます。

| コマンド | エイリアス | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| `:add [ニックネーム] [URL(任意)] [タイトル(任意)]` | `:a` | 現在のタブ、指定 URL（`http://`/`https://`）、または `javascript:` ブックマークレットを登録。`:add` 入力中は既存フォルダ・ニックネームの補完や登録対象プレビューを表示します。 | `:add note 議事録` / `:add mdlink javascript:...` |
| `:addall [ニックネーム]` | `:aa` | 現在のウィンドウで開いているすべてのタブ（`chrome://` 等を除く）を指定したニックネームで一括登録します。 | `:aa workspace` |
| `:rm [ニックネーム] [URL(任意)]` | — | 指定したニックネームまたは特定の URL エントリを削除します。 | `:rm old-site` |
| `:ls` | — | ブックマーク一覧（管理画面）を新しいタブで開きます。 | `:ls` |
| `:prefs` | — | 設定画面を開きます。 | `:prefs` |
| `:help` | — | 本ヘルプ・ドキュメントページを開きます。 | `:help` |

:::note[ニックネームの入力ルール（禁止文字バリデーション）]
コマンド登録・管理画面の編集・JSON インポートにおいて、システムと競合する文字（**空白文字、`:`, `;`, `\`, `%`, `?`, `#`, `&`, `=`, `*`, `"`, `'`, `` ` ``, `<`, `>`, `|`、および制御文字・ゼロ幅文字**）はニックネームに使用できません。フォルダ階層区切りとしてのスラッシュ **`/`** は利用できます。
:::

## 管理画面（`:ls`）

パレットで **`:ls`** を実行するか、パレット右上のリストアイコンをクリックすると管理画面（`list.html`）が開きます。

- **インライン編集**: ニックネーム・タイトル・URL の各セルをクリックするだけでその場が入力欄になり編集できます（`Enter` またはフォーカスアウトで保存、`Esc` でキャンセル）。動的 URL（`%s`）の場合は引数省略時のデフォルト値（`default_value`）もあわせて編集できます。
- **列別フィルター**: ニックネーム・タイトル・URL の各列ヘッダーにあるフィルターボタンから、スペース区切りの AND 部分一致でリアルタイムに絞り込めます。
- **並び替え**: ツールバーから「デフォルト順」「最終使用日時（新しい順／古い順）」「スコア（高い順／低い順）」を選択できるほか、列ヘッダーでのソートにも対応しています。
- **フォルダ操作バー**: 上部のフォルダ絞り込みで特定フォルダを選択すると、そのフォルダの「一括オープン」「フォルダ名変更」「フォルダ削除」をワンクリックで実行できます。
- **インポート / エクスポート / JSON 編集**:
  - **インポート**: Nickmark の JSON ファイルおよび Chrome 標準のブックマーク HTML ファイルに対応。取り込み前のプレビュー確認、取り込み先ベースフォルダの指定、マージ／上書きの選択が可能です。
  - **JSON で編集**: 組み込みの JSON エディタで全データを一括編集できます。
  - **エクスポート**: 現在のデータを JSON ファイルとしてバックアップ保存します。

## 設定画面（`:prefs`）

パレットで **`:prefs`** を実行するか、パレット右上または管理画面右上の歯車アイコンをクリックすると設定画面（`preferences.html`）が開きます。

- **Google アカウント同期**: デバイス固有の大容量ローカル保存（`chrome.storage.local`、実質無制限）と、複数デバイス間で共有できる Chrome 同期ストレージ（`chrome.storage.sync`、上限 100KB・自動 8KB チャンク分割）を切り替えられます。切り替え時にはローカルとクラウドのデータ件数・更新日時を比較して選択できるデータ移行ダイアログが表示されます。
- **使用言語**: `English` / `日本語` をリロードなしで即座に切り替えられます。
- **一括オープンの安全上限件数**: フォルダ一括オープン時に確認なしで自動展開する最大タブ数（1〜100件、既定 `20` 件）を設定できます。
- **別タブで開く設定**:
  - 「デフォルトで別タブで開く」: 有効時、修飾キーなしの `Enter` でも新しいフォアグラウンドタブで開きます。
  - 「“新しいタブ”のときはそのタブで開く」: 上記が有効な場合に表示されるサブ設定で、現在のタブが新しいタブページのときだけは現在のタブで開きます。
- **ブラウザ履歴検索**: オプトインで検索候補下部にブラウザ履歴を表示するかどうかを設定できます。
- **定番プリセット（全 18 種）**: チェックボックスをオンにするだけで、よく使う検索サービス（動的 URL 15 種）と実用ブックマークレット（3 種）を即座に有効化できます。有効化した ID のみを保存するためストレージ容量をほとんど消費しません。
  - **検索サービス（15 種）**: `g` (Google), `b` (Bing), `y` (Yahoo! ※言語自動切替), `nv` (Naver), `bd` (Baidu), `ddg` (DuckDuckGo), `yt` (YouTube), `gh` (GitHub), `map` (Google マップ), `tr` (Google 翻訳), `wiki` (Wikipedia ※言語自動切替), `amz` (Amazon), `x` (X / Twitter), `npm` (npm), `mdn` (MDN Web Docs)
  - **ブックマークレット（3 種）**: `mdlink`（現在ページの `[タイトル](URL)` をコピー）, `htmllink`（現在ページの `<a href="URL">タイトル</a>` を HTML＋プレーンテキストでコピー、Teams 等対応）, `wayback`（Wayback Machine で開く）

## 📥 JSON の仕様

管理画面の JSON エディタ・エクスポート・インポートでは、以下の仕様に基づく JSON 形式を使用します。

### フィールドの説明

- **`bookmarks`**: ルートとなるオブジェクトです。
  - **`{ニックネーム}`**: `bookmarks` 内の各キーがニックネーム（スラッシュ区切りでフォルダ表現可）となります。値はブックマークエントリの配列です。
    - **`url`**: 遷移先の URL または `javascript:` ブックマークレットコードです（必須）。
    - **`title`**: ブックマークのタイトルです。
    - **`score`**: 使用頻度と経過日数に基づく指数減衰スコアです。数値が大きいほどサジェスト時の優先順位が上がります。
    - **`last_used_at`**: 最後に使用した日時のタイムスタンプ（ミリ秒）です。
    - **`created_at`**: ブックマークを登録した日時のタイムスタンプ（ミリ秒）です。
    - **`is_pinned`**（任意 / boolean）: `true` の場合、同じマッチ度ティア内で最上位に固定表示されます。
    - **`default_value`**（任意 / string）: URL に `%s` を含む動的 URL において、引数を省略して開いた際に `%s` へ展開されるデフォルト値です。

### 具体的な例

```json
{
  "bookmarks": {
    "gh": [
      {
        "url": "https://github.com/%s",
        "title": "GitHub Repository / User",
        "score": 24.5,
        "last_used_at": 1715731200000,
        "created_at": 1715731200000,
        "is_pinned": true,
        "default_value": "sawarame/Nickmark"
      }
    ],
    "work/mail": [
      {
        "url": "https://mail.example.com",
        "title": "Team Webmail",
        "score": 10.0,
        "last_used_at": 1715731300000,
        "created_at": 1715731100000
      }
    ]
  }
}
```
